# 模块化背面丝印SVG

按2026-10-19用户导出网表制作，共27张独立接口图块；生成日期2026-10-20。
本文件集没有修改原理图、PCB、封装或网表。

## 使用

1. 从 `01_正常阅读SVG` 选择需要的图块，导入嘉立创EDA的底层丝印层。
2. 按文件原始毫米尺寸导入。文字是实际矢量路径，没有字体依赖。
3. 在EDA底面视图检查：文字应像直接看PCB背面一样读正。如果导入操作未正确处理方向，使用EDA镜像，或选用 `02_水平镜像SVG_备用` 中同名文件。两种方式二选一，避免重复镜像。
4. 每张是“编号对照表”，不是连接器实物脚位、焊盘位置或接线端视图；列的位置不代表PCB左右。只按PCB实际焊盘号对应，并放在背面空白区域。
5. `全部模块总览_非PCB排布.svg` 与PNG只用于选图和核对，不是当前PCB的整体排版。没有最新板框、底面元件及孔位坐标，因此图块不绑定PCB位置。
6. 预览确认图块没有被缩小；正文字高1.1mm、标题字高1.3mm、笔画0.15mm。缩小会降低可制造性。丝印距裸露焊盘建议至少0.2mm，避开螺丝垫圈和底面器件。

## 电气标注

- 只列插接功能针；GH/USB的额外机械接地脚不列入线束针序。MicroSD图块单独注明PAD NUMBER TABLE并列出全部14个封装焊盘。
- MAIN_J101为主载板DC输入；PANEL_J101为前面板10针接口，不可混用。
- J602-8为未连接，不能按某些方案概述中的RSTO文字视作已接复位。
- 小板J101-3实际未连接；主板J502-3为AX_3V3，线束可保持1对1，不代表小板使用此电源。
- J703标ACC SPI，不锁定外部模块型号。选ADXL345时仍需匹配线序和SPI模式3驱动；此图不表示ADXL355/345驱动兼容。
- J401的HOST表示主板控制器侧。丝印HOST_TX/HOST_RX沿用当前PRN_HOST_TX/PRN_HOST_RX网络定义；不要因打印机端也标TX/RX而自行再次交叉。
- J301/J304负端是MOS开关节点；J601两端都是桥式功放输出，都不能当GND。
- Nano两排采用官方排针编号，1脚位于USB-C端；图是针号表，不是底面左右位置图。
- J801对应AX7010的J11，不是相机J10；40针排线必须1对1。
- `引脚与丝印对照.csv` 提供每个图块的原始网名；匿名电源节点用功能名显示。

## 制造与验证

SVG使用毫米单位，只包含透明背景、线段路径，无位图、外部链接、字体、裁切或复用引用。
制造参考：https://jlcpcb.com/capabilities/pcb-capabilities （字高≥1mm、线宽≥0.15mm）。
最终以EDA导入后的底面视图、实际尺寸和Gerber预览为准；本次没有实际EDA导入或PCB DRC结果。
