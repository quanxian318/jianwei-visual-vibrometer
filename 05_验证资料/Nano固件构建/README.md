# Nano ESP32构建验证

2026-10-30，Nano固件 **0.2.1** 使用实际板包完整编译通过。以提交`5cad5b8e2121a96ab0f65cc9045601560e1dfbbf`为基础增加J605 UART0调试，USB-C与J605复用原有命令，输出采用独立限长队列分段发送。39个输入文件与构建暂存副本逐字节核对；精确内容见验证JSON中的源文件哈希，源码不是基础提交的原样副本。

- [工具链、输入文件与产物哈希](构建验证.json)。
- [完整构建输出](build.log)：程序972037字节（30%），静态内存103276字节（31%）。
- [主机测试结果](host_tests.log)：控制台10类场景（包含400条并发日志）、原有WAV解析和APP网关测试均通过；使用已安装的WSL g++，没有新增依赖。
- [预编译文件](../../06_软件与FPGA/nano_esp32/bin/)与[烧录说明](../../06_软件与FPGA/nano_esp32/README.md)。
- [语音合成记录及文件](../../06_软件与FPGA/nano_esp32/sd_card/)：五条选定女声WAV，格式正确；从已制作的FAT32语音卡读回，SHA256与源文件一致。

主机控制台测试覆盖UART0初始化、双入口独立命令、CR/LF/CRLF、USB未连接时使用J605、2500字节以上回复通过64字节FIFO、USB停读不阻塞UART、队列回绕/满载、超长命令拒绝、USB断线清理、部分写入及四线程并发日志。重现命令见Nano固件README，测试替身不模拟电气性能。语音文件未改动，已有WAV格式和卡上文件完整性验证仍适用。

**本版本未烧录，J605、板端播放、NFC/SD并发、载板UART及整机外设未完成实物验收。** 此前0.2.0的DFU上传与短USB命令响应已验证，不等于0.2.1验证。Nano曾出现独立USB供电时RESET约0.6V的硬件异常，需先修复或在正常Nano上联调。PS/APP既有问题见[三侧审查](../三侧对接/三侧对接审查.md)，本次没有修改PS、PL或APP实现。
