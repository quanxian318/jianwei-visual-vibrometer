## 位移跟踪结果

两段均为 1280×720、约 29.997 帧/秒：视频一 300 帧、约 10 秒；视频二 266 帧、约 8.9 秒。每段预先选两个端部区域、一个平坦板面、一个机架区域，ROI 均为 64×64、搜索半径 8 像素。未按频谱结果反复选择“更好看”的 ROI。

| 视频/区域 | 当前质量门限 | 结果含义 |
|---|---|---|
| 视频一两个端部 | 全片通过 | 能跟踪图像运动，但尚未扣除相机/整体运动 |
| 视频一平坦板面 | 初始化失败，300 帧无效 | 灰度纹理不足；没有输出有效频率或幅值 |
| 视频一机架 | 全片通过 | 与端部有明显共同运动，不能把端部谱峰直接认作电机频率 |
| 视频二端部上角 | 4 帧触及搜索边界 | 整段拒绝，不输出有效频率或幅值 |
| 视频二端部下角 | 7 帧触及搜索边界 | 整段拒绝 |
| 视频二平坦板面 | 148 帧低质量、45 帧触边 | 整段拒绝 |
| 视频二机架 | 174 帧低质量、52 帧触边 | 整段拒绝；不能作为合格的相机补偿参考 |

视频一的算法输出（仅图像运动，不是被测物真实振动指标）：

| 区域 | X 主峰 Hz | Y 主峰 Hz | X 去趋势峰峰值 px | Y 去趋势峰峰值 px |
|---|---:|---:|---:|---:|
| 端部下角 | 0.926 | 0.513 | 10.705 | 10.743 |
| 端部上角 | 0.949 | 0.513 | 12.412 | 8.646 |
| 机架参考 | 0.871 | 0.513 | 15.980 | 14.007 |

原始 X 位移出现数十像素缓慢移动，Y 方向端部和机架也有共同变化。上述低频峰接近且机架幅值不小，因此不能判定为板片固有频率。程序 `valid=true` 在这里表示通过已实现的追踪/采样质量检查，不代表已经排除共同运动或完成光学精度验证。

约 30fps 对应 15Hz 奈奎斯特频率，视频无法排除更高频电机运动混叠到低频；当前搜索频带上限还限制为 0.4×实际帧率。视频 PTS 是容器呈现时刻，并未验证传感器曝光时刻、快门、滚动快门或视频转码是否保留原始采样。没有实物尺寸标定，所以全部位移保留为原生像素。

本次没有投影开/关对照，因此不能用这次结果证明 650nm 投影能够解决少纹理面内位移测量。当前最直接的实验改进是固定相机，在板片端部和独立背景各布置随各自材料移动的哑光特征，并记录已知激励频率作对照。

## 具体修正

- LED1/J301：普通照明；LED2/J304：12V、650nm 十字线投影，固定 100% 输出、只开关。
- 启用 `laser.off_during_measurement` 时，采集和分析期间主控拒绝 `laser on=true`，不改变输出状态。
- 采集中不能通过 `set laser_off_during_measurement=false` 绕过策略。
- 实时页、视觉深度页、设置页同步禁用对应操作；预览恢复后重新可用。
- 正常测量结束保留原来的恢复逻辑，掉电/关机保护关断不受影响。
- 界面和操作说明使用“十字投影”，字库已重新生成。

验证：修复前新增 3 项检查失败；修复后六组单元测试、36 项应用检查通过，编译未见 warning/error。另导出并检查了更新后的界面。日志在 `led2_checks/`，验证摘要及修改文件 SHA256 在 `led2_checks/verification.json`。未做新的 ARM 构建、Vivado 综合或上板测试。

## 如何复现

`scripts/measure_clip.cpp` 直接链接生产库，调用 `NccTracker` 与 `analyzeCapture`，不复制或替换算法。`scripts/run_clips.py` 在 WSL 用已有 FFmpeg 灰度解码并导出实际 PTS，运行该工具及已有 `vision_ref`。四个 ROI 是独立离线检查，不表示主应用已经支持多 ROI。

`scripts/render_results.py` 用已有 Python/Numpy/Pillow 将 C++ 输出制成图和对比视频；两段各前 4 帧的 G0/放大/带通/能量四种输出又与 Python 模型逐位核对通过。没有为本次测试安装新依赖，也没有重新跑 PL RTL。

`run_clips.py` 的 BUILD 指向本机已有 WSL 构建目录；在另一台机器复现时将它改成实际构建目录，并先编译 `measure_clip.cpp` 链接 `libvibmon.a`。中间的大尺寸解码帧和 RGB 编码缓存已清理；保留原视频、短比对输入、C++ 输出、CSV、图、对比视频及复现脚本。
