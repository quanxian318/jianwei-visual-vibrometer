## 启动与恢复

运行 Start_Frequency.cmd（G盘Xilinx必须可用、JTAG/网线已连、板和屏已供电）。会重新加载DDR中的程序，旧版暂时停止运行，原文件不变。失败自动尝试加载保留的跟踪V1。手动恢复也可运行原桌面“AX7010 双目标记跟踪 V1”。不设置开机自启。

运行成功后：

- http://127.0.0.1:8769/ 板上频谱页面。
- http://127.0.0.1:8767/ 沿用原跟踪监看/坐标记录服务，板重启后CSV的host_acquisition_epoch区分不同运行。8767的网页刷新率不是相机采样率。
- 旧8768是电脑复算诊断，不是板上频谱；它的旧静止基线不能跨本次重新初始化直接当作新基线。

频谱页面按钮需人工确认静止，记录30秒新板上基线；基线易失，重新启动程序后需重录。控制仅支持开始/清除基线，不能写任意地址。HTTP绑定127.0.0.1、限定JSON和同源，板UDP仍只接受192.168.1.100。当前网页只提供“开始”按钮。

## 处理位置和方法

原FPGA负责双路采集与HDMI，CPU1做四个ROI的亚像素平移跟踪及四路FFT。**FFT使用AX7010的ARM，不是已实现PL FFT加速。**网页只解析板上FFT结果和画图，verify_frequency.py中的NumPy是独立数值验证。

256点窗，去均值和线性趋势、Hann窗、实数FFT，单边幅度谱，DC/Nyquist不翻倍。每64个样本更新一次，约45Hz时为5.68秒窗口、1.42秒更新周期、0.176Hz频率栅格。这不等于0.176Hz精度；滑窗有历史延迟，不能表示瞬时振动。

LOST、丢序号、非递增时间戳、任一采样间隔偏离窗口平均超过10%的窗口拒绝，不填补。CPU观察时间戳不等于传感器曝光硬同步。左右目标都扣除各自背景参考移动；参考点自身噪声也会加进结果。

静止基线只纳入开始命令之后完整采到的有效窗，保存每频点最大谱幅。30秒后四路各至少10窗才就绪，不足则延长至最多60秒，仍不足明确失败。基线窗口的拟合趋势总变化或去趋势RMS超过0.5像素时也拒绝，避免明显移动被算入“静止噪声”；这些是初始工程保护阈值，不是精度标定。0.5～18Hz范围中，峰值超过基线同频与邻频点包络3倍才显示候选；未满足时显示“无可靠候选谱峰”。该门限不是已标定误报/检出率，不用于安全结论。数据停止更新不继续显示有效候选。

显示增加紫色背景参考框（无效时红色），网页提供目标与参考的独立有效率。屏幕右侧时域曲线仅为显示扣除最新位移偏置，保持每原生像素对应50显示像素的比例；原始坐标、基线、FFT输入不受此显示居中影响。背景孔阵是临时参考，不是独立仪器验证的静止基准；重复/反光纹理会失效，明天应换成固定在独立背景上的清晰、唯一的哑光标记。

2026-10-18参考初始化修正：在原参考ROI中心±12原生像素内、步长6像素比较25个候选窗；维持原方差与二维Hessian条件阈值，按det(H)/(trace(H)+1)选择通过的更强纹理。初始化成功后参考模板固定，不在运行时自动重选或漂移更新。共享reference_seed记录所选锚点；ROI采集位置不改，参考坐标仍是原生绝对像素。新增偏移模板自检验证零运动不会被误认为选择偏移量。该改动改善初始化可用性，不保证独特纹理或物理静止，重复孔阵仍应替换。

未做双目内外参或像素物理尺寸标定；输出原生像素估计，不是毫米/微米，不是3D位移精度证明。约45Hz普通采样不能排除22.5Hz以上信号混叠到低频。即使两路同频也不能排除。明天必须先用已知低频激励做实物验证，不能直接把电机的低频谱峰认作实际转频。

- 部署日志 deploy.log：相机ID、跟踪与频谱启动自检。
