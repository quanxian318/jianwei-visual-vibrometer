## Board-level evidence

AX7010 user manual describes VCC3V3 and separately sequenced Bank35 VCCIO. J11 power pins therefore are named HOST_3V3 here, not treated as proof of Bank35 rail validity. All outputs directed into PL, plus every I2C path, default disabled until configured PL explicitly asserts READY. READY has a 1k external pulldown and a Schmitt input conditioner on the carrier.

Arduino official ABX00083 datasheet confirms VIN=6–21 V, GPIO=3.3 V, and no active 5 V VBUS output when VIN powered. Nano-side receiver buffers use its own 3.3 V rail. Its SPI, I2S and voice-mode outputs are isolated against USB-only Nano power.

## Verified printer interface definition

The user-provided TTL drawing defines pin1 VIN as printer power+, pin2 CTS as printer output (high=busy, low=ready), pin3 TX as HOST-to-printer data, pin4 RX as printer-to-HOST data, and pin5 GND. For the selected 12 V printer, the standard design connects switched 12V_PRN to pin1 and uses the single five-wire harness for power and UART. Do not cross pins3/4 a second time based on printer-side TX/RX naming. The existing J11 UART pin allocation is unchanged. Current effective printer page: V1.4.1_打印机接口设计.md.

## Hardware illumination permission

Current page: V1.4.2_补光硬件控制设计.md. A maintained normally-open pushbutton connects 3V3_D to a filtered, Schmitt-conditioned input through a separate GH2 connector J29. Opening the contact forces both LED drive outputs low independently of software PWM. Existing panel J12 and J11 allocation are unchanged. Nano A5 is now an input reporting LED_HW_STATE; the Nano PFAIL receiver becomes a dual SN74LVC2G125 to receive PFAIL and LED_HW_EN using NANO_3V3. Normal/USB-only power cases require prototype verification. Printer-before-illumination shutdown remains the software workflow; the new hardware gate is qualified by SAFE and the physical switch.


## TOF and extension evidence

User selected the black six-pin VL53LXX-V2 module: VIN/GND/SCL/SDA/GPIO1/XSHUT. Seller specifies VIN 3.3–5 V and shows an LDO, bidirectional MOS I2C translation, host-side 10k pullups to VIN, and GPIO1/XSHUT pullups to internal VDD. Use 3.3 V VIN; retain module-side XSHUT pullup with carrier open-drain control. Seller title says VL53L1X while diagram says VL53L0X, so read the actual ID before selecting firmware. ST VL53L1X: AVDD 2.6–3.5 V, maximum I2C 400kHz, default 7-bit address 0x29 (8-bit write 0x52), GPIO1 open drain, XSHUT active low, peak chip current may reach 40mA. Model-ID register 0x010F=0xEA and module type 0x0110=0xCC after reset. Sources: https://www.st.com/resource/en/datasheet/vl53l1x.pdf ; https://www.st.com/resource/en/datasheet/vl53l0x.pdf . Module voltages/pulls remain seller evidence until measured.

J28 is a generic 3.3 V I2C2 port, 4.7k pullups and initial 100kHz, not a populated thermal module. J30 duplicates I2C1 for expansion. J31 shares AX sensor SPI, using independent K17 CS and CS-qualified 1G125 MISO. AX7010 local manual confirms CP2102 USB UART and FT232HL USB JTAG. Nano J22 is independent D1 TX/D0 RX/GND debug UART, not the D2/D3 AX link.
