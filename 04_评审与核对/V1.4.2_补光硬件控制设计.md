# 见微视觉测振仪：补光硬件控制设计 V1.7

本页说明补光硬件许可与Nano A5状态输入。整机电路统一执行[完整原理图设计方案V1.7](见微_AX7010外围载板原理图设计方案_V1.7.md)。

## 1. 操作方式

新增一个保持状态的自锁按钮K_LED，两路补光共用此硬件许可：按钮弹起（触点断开）时强制关灯；按钮按下锁定（触点闭合）后允许AX7010控制开灯与PWM亮度。它不是直接把灯带接到12V的功率按钮。

| K_LED | READY/PFAIL正常 | AX7010占空比 | 灯带 |
|---|---|---|---|
| 断开 | 任意 | 任意 | 必须关闭 |
| 闭合 | 否 | 任意 | 必须关闭 |
| 闭合 | 是 | 0% | 关闭 |
| 闭合 | 是 | 0～100%之间 | 按PWM调光 |
| 闭合 | 是 | 100% | 持续点亮 |

自锁按钮在断电时保留机械位置。重新上电时READY仍默认为0；若按钮保持闭合，系统初始化后恢复硬件许可，是否点亮由AX7010软件的PWM初值决定。AX7010软件应将PWM初值设为0，直到明确启动补光。

## 2. 按钮接口与滤波

保持面板J12的GH1.25 10P针序，另增J29，GH1.25卧贴2P（JST SM02B-GHS-TB或规格对应的国产座）。

| J29针 | 网络 | 连接 |
|---|---|---|
| 1 | 3V3_D | 按钮触点一端 |
| 2 | LED_SW_RETURN | 按钮触点另一端 |

K_LED使用SPST保持型常开触点；弹起断开，按下自锁闭合。采购有明确触点定义、允许低电平小电流工作的自锁按钮，优先使用镀金信号触点。需要带灯时，指示灯按额定电压另接供电，不串进使能触点。

```text
J29-1 3V3_D ── K_LED ── J29-2 LED_SW_RETURN
                                  │
                                 1kΩ
                                  │
                              LED_SW_FILT
                                  ├──10kΩ──GND
                                  ├──1µF───GND
                                  └──SN74LVC1G17输入A
                                         输出Y→LED_HW_EN
```

SN74LVC1G17DBVR由3V3_D供电，旁路100nF。闭合时滤波节点名义电压为3.3×10/11≈3.0V；断开或线束拔掉时由10kΩ下拉为低。施密特输入处理RC慢沿，避免直接用普通CMOS输入接缓慢变化的电压。按钮只承载约0.3mA使能电流，不承载灯带约0.75A电流。

RC用于降低机械抖动和干扰，不保证任意按钮完全无抖动；关灯会有约十几毫秒量级的释放延迟，最终按元件容差和实物验证。用于测量的稳定补光应在按钮状态稳定后启动。

## 3. 硬件允许逻辑

使用一颗新增的SN74LVC2G08DCUR（或正式原理图中确有可用的同型号空余与门），VCC=3V3_D，旁路100nF：

```text
SAFE = READY AND PFAIL_N
LIGHT_ALLOW = SAFE AND LED_HW_EN

LED1_DRIVE = LED1_PWM AND LIGHT_ALLOW
LED2_DRIVE = LED2_PWM AND LIGHT_ALLOW
```

新增与门输入分别接SAFE、LED_HW_EN，输出为LIGHT_ALLOW。原两路PWM与门的许可输入改接LIGHT_ALLOW。未用与门的输入接GND，输出不接。LED1_PWM、LED2_PWM由AX7010输出，载板侧各保留100kΩ下拉。

硬件关灯由与门完成，不依赖Linux、Nano或UART消息。当软件仍输出100%占空比时，断开K_LED仍会把两路驱动信号拉低。

补光硬件许可由SAFE与自锁按钮决定；打印前关补光由软件任务流程执行。

## 4. 功率驱动连接

两路UCC27517DBVR维持现有连接：VDD Pin1接5V_AUX，GND Pin2接地，IN+ Pin3分别接LED1_DRIVE或LED2_DRIVE，IN− Pin4接地，OUT Pin5经15Ω接AOD4184A Gate。Gate对Source保留100kΩ下拉，驱动器旁放1µF+100nF。

```text
12V_MAIN → 分支保险丝 → 灯带正极
灯带负极 → AOD4184A Drain
AOD4184A Source → GND
```

灯带仍通过MOS低边开关控制。只用于本方案12V灯带，不把此电路直接用于没有限流的裸大功率LED。

## 5. 按钮状态读取

Nano A5由备用脚改为LED_HW_STATE输入。LED_HW_EN不能不经处理直接接Nano A5，以覆盖Nano仅由USB供电的调试状态。

将原Nano侧PFAIL单路接收缓冲改为SN74LVC2G125DCUR，VCC=NANO_3V3，旁路100nF：

| 通道 | 输入 | 输出 | /OE |
|---|---|---|---|
| 1 | PFAIL_N | Nano A6 | GND |
| 2 | LED_HW_EN | Nano A5 | GND |

两个缓冲输入各加100kΩ下拉。该器件有明确Ioff规格；接收侧电源为Nano自身3.3V。载板逻辑电源断电时LED_HW_STATE读为关闭，不向载板注入Nano USB电源。

Nano对状态变化做20～30ms软件消抖，经既有UART报告AX7010，用于界面显示和采集状态判断。硬件关灯不等待这一上报；软件开始采集前检查许可状态，检测到硬件关闭时中止当前采集段或将该段标为无效，避免暗帧被当成目标振动。软件状态同步存在延迟，帧质量检查仍按测量流程执行。

界面应分别显示“硬件允许状态”和“软件补光命令/亮度”，不要仅凭软件占空比显示灯已实际点亮。A5作为状态输入，不再分配给其他外部控制功能。

## 6. 新增或调整元件

| 项目 | 选择 |
|---|---|
| K_LED | 自锁保持型按钮，常开信号触点 |
| J29 | GH1.25卧贴2P，SM02B-GHS-TB及配套线束 |
| 按钮滤波 | 1kΩ串联、10kΩ下拉、1µF陶瓷 |
| 输入整形 | TI SN74LVC1G17DBVR |
| 许可与门 | TI SN74LVC2G08DCUR；按实际空余通道决定是否新增 |
| Nano接收缓冲 | TI SN74LVC2G125DCUR替代原PFAIL单路缓冲 |
| 去耦 | 新增IC各100nF |

复用已核对的器件类型，不修改J11管脚及XDC。两路补光的硬件许可共用一个按钮，软件亮度仍可分别设定。

## 7. 验证

1. 使AX7010输出100% PWM，按钮断开时两路UCC27517 OUT和MOS Gate应为低、灯灭。
2. READY=0或PFAIL_N=0时，即使按钮闭合、PWM=100%，仍应关灯。
3. 正常电源和READY下，按钮闭合后验证0%、中间占空比及100%的灯光状态。
4. 拔掉按钮线束，应关灯；观测按钮切换过程和RC节点波形。
5. 重载PL、分别给Nano USB和整机供电，验证默认状态及无反向供电。
6. 检查A5上报、界面许可显示、关闭补光时当前采集段的处理。
