# 见微视觉测振仪：AX7010外围载板原理图设计方案 V1.7

日期：2026-10-14。当前完整设计方案，整合打印机PH2.0五针供电、补光自锁按钮、状态指示和语音报警。关键器件参数以本任务已核对的厂家资料为依据；本文件不是已完成ERC的EDA原理图，也不是样机验证报告。

## 1. 系统组成

主电源稳压12V/5A，DC插口5.5×2.5mm、中心正极、额定至少5A。AX7010使用原5V电源入口；AN5642直接接AX7010 J10，载板接J11。微雪7inch HDMI LCD(H)的HDMI及Touch接AX7010，Power Only由载板独立5V供电。Nano ESP32采用Arduino官方ABX00083。

载板包含两路12V补光输出、12V热敏打印机PH2.0×5P接口、PN532、黑色六针TOF模块、LSM6DSV、SHT40、Nano侧Micro SD、DS3231、EC11、K1、补光自锁按钮、五颗WS2812状态灯、独立报警灯及蜂鸣器、I2S扬声器。首版热成像只留I2C2扩展接口，不装MLX90640。可选ADXL355、转速、继电器和两线风扇。预留三组I2C接入点、共享SPI扩展口及调试口。

```text
12V输入→保险丝→总开关→防反接/TVS→5mΩ采样→12V_MAIN
  ├─TPS5430→5V_AX→AX7010→AN5642
  ├─TPS5430→5V_LCD→屏幕Power Only
  ├─TPS5430→5V_AUX→NFC/语音/面板/辅助电路
  │                 ├─TLV1117LV33→3V3_D
  │                 └─TPS7A2033→3V3_SENS
  ├─LMR16006Y→9V_NANO→Nano VIN
  ├─补光MOS驱动×2→12V灯带
  ├─高边开关→12V_PRN→打印机五针VIN
  └─12V报警灯/蜂鸣器/风扇
AX7010 J11↔载板缓冲与I2C开关↔各外围
```

## 2. 输入电源

J1为明确有5A以上规格的5.5×2.5mm DC插座；切换触点不用时悬空。F1候选6.3A慢断、可更换座，最终按浪涌及熔断曲线确定。SW1须有≥12VDC/6A直流规格。

防反接Q1选AOS AO4407A：Drain接输入，Source接12V_PROTECTED，Gate经10kΩ接地；BZT52C12阴极接Source、阳极接Gate。TVS选Littelfuse SMBJ13A单向，阴极接12V_PROTECTED、阳极接地。母线放470µF/35V、10µF/50V、100nF/50V。

AO4407A为-30V器件，-10V栅压下RDS(on)≤13mΩ；5A损耗约0.325W，留散热铜。SMBJ13A钳位规格约21.5V，不是持续过压稳压器；Nano经独立9V降压，其他直接12V负载仍按各自供电规格使用。F1不代表精确5A限流。

## 3. 三路12V转5V

三路相同TPS5430DDAR，分别形成5V_AX、5V_LCD、5V_AUX。芯片额定3A，正常总负载受60W输入和散热限制。

| TPS5430脚 | 连接 |
|---|---|
| 1 BOOT | 10nF/25V接PH |
| 2、3 NC | 悬空 |
| 4 VSENSE | 反馈中点 |
| 5 ENA | 常开，按手册允许悬空，留测试点 |
| 6 GND、PowerPAD | 接地、散热过孔 |
| 7 VIN | 12V_MAIN |
| 8 PH | 电感输入、续流二极管阴极 |

外围：输入2×10µF/50V X7R+100nF；电感Bourns SRP1038A-150M，15µH、Irms6.25A、Isat10A；肖特基MCC SK54B-LTP（5A/40V SMB），阳极接地；主输出电容Panasonic 10TPB220M（220µF/10V、ESR最大40mΩ）、100nF旁路；反馈上10kΩ/下3.24kΩ，1%。VOUT≈4.990V；12V输入时电感纹波约0.389A。

输出电容使用TI参考方案；10TPB220M厂家标注NRFND，采购不到时需按ESR与环路要求重新选择并验证，不能任意换成陶瓷电容。AX7010和屏幕内部的额外电容计入启动及动态负载检查。

5V_AX经≥3A端子及短线接AX7010原电源入口，不从J11-2反向供电。5V_LCD经2A分支保险丝接USB-A的VBUS/GND，D±不接，丝印LCD POWER ONLY / 5V。

|---|---|

| 2 GND | 地 |
| 3 FB | 反馈中点 |
| 4 SHDN | 按手册允许悬空，常开 |

## 5. 3.3V电源域

| 网络 | 来源、用途 |
|---|---|
| HOST_3V3 | J11-39/40，经0Ω；只供输出指向PL的接收缓冲 |
| 3V3_D | 5V_AUX→TI TLV1117LV33DCYR，板内管理、SD、Nano外围及控制逻辑 |
| 3V3_SENS | 5V_AUX→TPS7A2033PDBVR，传感器及对应发送缓冲 |
| NANO_3V3 | Nano本机3.3V，只供Nano侧接收及上拉 |
| 3V3_PRN | 12V_PRN→TLV76033DBZR，打印机发送缓冲及空闲上拉 |

各3.3V不并联。HOST_3V3入口1µF，各缓冲100nF，规划小电流；它不是Bank35 VCCIO有效的证明，所有进入PL的主动驱动和I2C均由READY隔离。

TLV1117LV33：IN3接5V_AUX，GND1接地，OUT2及散热片为3V3_D；输入10µF、输出22µF X7R。芯片允许陶瓷输出电容，输入工作上限5.5V。连续先预算350mA，损耗约0.595W，留散热铜。

TPS7A2033PDBVR：IN1接5V_AUX，GND2接地，EN3接IN，NC4悬空，OUT5为3V3_SENS；输入/输出各2.2µF，有效输出不得小于1µF。器件为300mA，本设计先按连续120mA、短时峰值200mA规划。每个传感器模块旁按需求放100nF及1～10µF。

## 6. 电流与欠压监测

INA226AIDGSR：VS=3V3_D、100nF旁路，A0/A1接地（地址0x40），I2C0连接；ALERT经10kΩ上拉3V3_D送TCA P1.6。RS=5mΩ、1%、≥1W，优选四端，IN+接输入侧、IN-接输出侧，VBUS接12V_MAIN。Kelvin引线独立从电阻焊盘取样。5A时压降25mV、损耗0.125W；Current_LSB=0.25mA、CAL=4096。采样监测不代替短路保护或打印脉冲测量。

TLV3011BIDBVR：OUT1=PFAIL_N，10kΩ上拉3V3_D；V-2接地；IN+3接12V分压；IN-4接REF5；V+6接3V3_D、100nF。12V_MAIN经100kΩ到分压点，12.7kΩ到地，1nF滤波，OUT经1MΩ正反馈到分压点。下降约10.8V、回升约11.2V为名义值，需计入B版本内部迟滞与误差实测。B版本输入支持V+=0时的fail-safe高阻。

PFAIL_N送PL及Nano A6，并参与大负载许可。无保持供电时只保证设计上及时阻止新任务，不承诺拔电后Linux正常关机或MQTT发送完成。

## 7. READY与隔离

J11-5 FPGA_READY加1kΩ对地下拉，经3V3_D供电的SN74LVC1G17得到READY。PL配置完成、UART空闲高/SPI片选高/PWM为0、控制器初值安全后置READY高；随后访问管理芯片和初始化外设。I2C0由READY直接打开，不依赖TCA先初始化。

缓冲选Nexperia 74LVC244APW,118（IOFF、5.5V容限、施密特输入）、TI SN74LVC1G125DBVR、SN74LVC2G125DCUR（明确Ioff）。不以SN74LVC125A证明断电隔离。

每组/OE经10kΩ拉到缓冲自身VCC，2N7002 Drain接/OE、Source接地、Gate接许可并有100kΩ下拉。许可高时使能。每芯片100nF，不用的输入接地、输出不接。FPGA侧输出信号预留100kΩ下拉，不用载板上拉直接驱动未供电的FPGA。

| 16路返回PL | 74LVC244×2 / HOST_3V3 | READY |
| AX→Nano TX/RTS | 2G125 / NANO_3V3 | READY |

## 8. I2C与TCA9555

| 总线 | 设备/7位地址 | 起始速率 | 器件侧等效上拉 |

| I2C1 | TOF默认0x29、SHT40 0x44，J30扩展 | 100kHz | 载板4.7kΩ与TOF模块约10kΩ并联，名义约3.2kΩ→3V3_SENS |

## 9. 硬件许可逻辑

SN74LVC2G08DCUR由3V3_D供电，各100nF，根据关系组合：

```text
SAFE = READY AND PFAIL_N
LIGHT_ALLOW = SAFE AND LED_HW_EN
LED1_DRIVE = LED1_PWM AND LIGHT_ALLOW
LED2_DRIVE = LED2_PWM AND LIGHT_ALLOW
PRN_EN = SAFE AND PRN_PWR_REQ
PRN_TX_ALLOW = PRN_EN AND PRN_COM_REQ
EXT_I2C_ALLOW = SAFE AND EXT_I2C_REQ
ESP_IO_ALLOW = Nano_A4 AND PFAIL_N
```

TCA在PL重配置时会保留寄存器，READY硬件门仍关闭负载。打印前关补光继续由软件任务流程执行，没有额外把打印请求接入LIGHT_ALLOW。

## 10. 补光与自锁按钮

灯带总长暂按0.6m、15W/m：9W、0.75A。两路各用UCC27517DBVR+AOD4184A，驱动器VDD1接5V_AUX、GND2接地、IN+3接LEDx_DRIVE、IN-4接地、OUT5串15Ω接MOS Gate；Gate-Source100k，驱动旁1µF+100nF。12V经分支保险丝到灯带正，灯带负接Drain、Source接地。AOD4184A在4.5V栅压下有导通规格，这里5V驱动。

K_LED为SPST自锁常开信号触点，选择允许小电流使用的按钮；J29 GH2的Pin1=3V3_D、Pin2=LED_SW_RETURN，按钮连接两针。RETURN串1k到滤波节点，该节点10k下拉、1µF对地，再进SN74LVC1G17（3V3_D、100nF），输出LED_HW_EN。闭合名义3.0V；断开/拔线低。按钮约0.3mA，不承载灯带功率电流。滤波关灯有约十几毫秒延迟，实测确定。

按钮断开必关；闭合后仍要求SAFE及软件PWM。机械位置断电保持，软件启动PWM=0。Nano A5经前述接收缓冲读取LED_HW_STATE，20～30ms消抖后上报AX；采集前检查许可，关闭时中止或标记该段无效，同时用帧质量检查覆盖上报延迟。

测量中固定亮度、曝光与增益。初调可用约20kHz PWM，正式采集优先检查100%常亮及灯带自身纹波；频闪需与实际曝光标定，不把VSYNC等同整帧同步曝光。

## 11. 打印机PH2.0五针

标准采用一条五芯线同时供电及通信。

| J13针 | 打印机定义 | 载板连接 |
|---|---|---|
| 1 | VIN，整机电源+ | 12V_PRN |
| 2 | CTS，高忙/低允许 | 5V容限非反相接收缓冲→PRN_CTS |
| 3 | TX，主机发送 | PRN_TXD→发送缓冲→100Ω→此针 |
| 4 | RX，主机接收 | 此针→接收缓冲→PRN_RXD |
| 5 | GND | 系统GND |

第3/4针不再次交叉。丝印VIN/CTS/HOST_TX/HOST_RX/GND；核对连接器朝向和实物1脚。选PH2.0座S5B-PH-K-S（卧插）或B5B-PH-K-S，配PHR-5；接口间距2.0mm。JST PH额定2A@AWG24，接口功能已确认，但峰值、脉冲占空比、温升及所购线束规格仍须验收。

打印支路：12V_MAIN→分支保险丝候选→AO4407A Source，Drain→12V_PRN→J13-1；Gate-Source47k，Gate经10k接2N7002 Drain、Source地、Gate=PRN_EN，栅源BZT52C12。栅源100～330nF焊位调边沿不是精确限流。附近470µF/25V+1µF+100nF。标准装配接通VIN，不再保留VIN定义未确认的DNP条件；无需另接两针电源线。

TLV76033DBZR：IN2接12V_PRN、GND3接地、OUT1为3V3_PRN，输入1µF/25V，输出1µF+100nF、10k泄放。发送SN74LVC1G125 VCC=3V3_PRN，A=PRN_TXD，Y串100Ω到J13-3，J13-3用10k上拉3V3_PRN；/OE按PRN_TX_ALLOW。接收J13-2/4用HOST_3V3供电的74LVC244、READY开启。

PRN_COM_REQ=0→停止采集/关补光→PRN_PWR_REQ=1→等待厂家启动时间→CTS低→开通信发送。发送中监视CTS，高时暂停，带超时；断电状态不采信CTS。停止时先确认任务实际完成，再关通信和电源，不能仅凭CTS低或UART空判断机械打印完成。分支保险丝最终按电流波形、连接器条件定型，3A不是已验收值。

## 12. Nano引脚、NFC与SD

两1×15母座，行距15.24mm，按官方尺寸与脚序，USB-C朝板边；BOOT0/BOOT1保持启动用途，RST经2N7002开漏接受ESP_RESET_REQ，GND共地。NANO_3V3不与其他3.3V并联，VBUS不接载板5V。

| Nano脚 | 功能 |
|---|---|
| D0/D1 | 调试UART |
| D2/D3 | 向AX发送/接收AX UART |
| D4/D5 | Nano RTS/CTS，对应AX CTS/RTS |
| D6 | ESP_IRQ |
| D7/D8/D9 | I2S BCLK/LRCLK/DIN |
| D10 | SD_CS |
| D11/D12/D13 | MOSI/MISO/SCLK |
| A0 | PN532 IRQ |
| A1 | SD卡检测 |
| A2 | 不接外部控制负载 |

Arduino编号模式使用丝印宏，GPIO号不与Arduino数字编号混用。UART发送与接收经隔离缓冲，接收侧空闲上拉到其自身电源；FPGA输出先设空闲高再开启READY。

J19 PN532 GH8：1=5V_AUX，2=GND，3=SCLK，4=MOSI，5=MISO，6=CS，7=IRQ，8=RSTO仅测试点。10µF+100nF，设置SPI；模块V3说明SPI3.3V，仿制板核对版本。PN532为Mode0/LSB first，SD为MSB first，分别配置SPI事务。

两路MISO先过3V3_D供电的SN74LVC2G125：SD通道/OE=SD_CS，PN通道/OE=PN_CS，两个Y并到MISO_BUS，再经NANO_3V3接收缓冲至D12。未选择模块硬件隔离；CS均10k上拉3V3_D，不同时选中两模块。Nano SPI/I2S输出经74LVC244，按ESP_IO_ALLOW开启；SPI接收及IRQ也按许可开启，防止USB独立供Nano造成倒供。

Micro SD SPI脚：1 DAT2→10k上拉，2 DAT3=CS，3 CMD=MOSI，4 VDD=3V3_D，5 CLK=SCLK串22～33Ω，6 VSS地，7 DAT0=MISO，8 DAT1→10k上拉。CS/CMD/DAT0预留上拉，卡旁22µF+100nF，CD→A1用NANO_3V3上拉。AX侧SD存系统和测量/视频，Nano SD存语音/配置/少量离线缓存。语音与NFC共享SPI需事务互斥和音频缓存。

## 13. 语音与扬声器

## 21. 功率、软件、布局及验收

功耗为估算而非实测，效率暂按88%：AX+相机5V/1.5A约8.5W；屏5V/0.85A约4.8W；辅助静态示例约2W（低亮灯，不含语音峰值）；Nano约1.2W；风扇等1.2W；补光9W，基础采集约26.7W。打印2A假设另24W，3A则36W。默认打印前结束采集、关补光，基础用电约17.7W，2A打印约41.7W，3A约53.7W，语音峰值另计并限音量/错开。12V5A输入60W不保证未知打印波形始终可用；测量电流、母线压降及PH触点温升后定型。

按四层设计：L1器件与功率、L2完整地、L3电源及少量信号、L4信号。开关电源高频回路紧凑，PH远离反馈；功率铜按层叠和温升计算；大电流回流不穿过敏感区；Nano/NFC天线净空；相机支架IMU刚性固定；传感器远离电源热源，留全部电源、READY/PFAIL及关键总线测试点。

相机采样率由AN5642配置与实测决定；30fps常规采样奈奎斯特上限15Hz、60fps为30Hz，实际留余量。统一PL时间戳，记录曝光、VSYNC、丢帧和传感器滤波延迟；不假定双目天然同步曝光，不靠插值恢复超过采样率的信息。

验收顺序：不接模块测保护/电源→各降压动态负载与温升→接AX相机HDMI→屏幕供电/USB触摸→READY/PFAIL与管理芯片→重配置及按钮硬件强制关灯→TOF芯片ID及各传感器→I2C/SPI扩展→Nano SPI共存/I2S语音及USB独立供电→打印文本/高黑度/启动电流与PH温升→组合负载与图像条纹/掉帧。功耗、声压和完整PCB ERC/DRC尚无验证结果。

待补齐：打印机峰值/有效值/浪涌、启动等待、波特率/命令与完成状态；TOF实物芯片ID、模块VDD和上拉实测；实际DC/PH/GH型号和线束脚序；目标测振频带/分辨率/实际帧率。分页绘图建议：输入监测、各电源、主控隔离、管理RTC、传感器、Nano外设、打印机、面板补光报警、扩展与调试。
