## 0  版本说明

本文件是首版原型载板的完整原理图设计方案，可按章节分页绘制原理图。关键器件参数以已核对的厂家资料和 AX7010 用户手册为依据；阻容值中的“初始值”需要在实际线缆和负载下验证。本文件不是已完成 ERC 的 EDA 原理图，也不是样机验证报告。

### 0.1 简化原则

> **核心原则**　凡是直接连到 FPGA 引脚的器件，都由 AX7010 J11-39/40 引出的 +3.3V（网络名 AX_3V3）供电，传感器 LDO 的使能也取自 AX_3V3。AX_3V3 与 Bank35 VCCIO 并非同一电源轨。本方案通过串联电阻和传感器上电延时处理正常上下电过程，首板测量时序后确认。只有真正来自其他电源域的信号（Nano、打印机、转速、掉电检测、5V 状态灯和补光驱动）才做电平或隔离处理。

> **上电时序说明**　AX7010 用户手册（第 9、38 页）：J11-39/40 是板上 +3.3V；Bank35 的 VCCIO 由另一颗 SPX3819 产生，上电顺序为 1.0V → 1.8V → 1.5V → 3.3V → VCCIO。因此正常冷启动时 AX_3V3 比 Bank35 早一小段时间。V1.10 对此做了限流（推挽输出串 1k）和延时（3V3_SENS 的 EN 加 RC，BAT54 提供快速放电支路），并在首板验收中实测这一时间差（第 19 章）；实测满足要求就保持直连，不满足再只给相关路径加使能。

### 3.2 INA226 功率监测

- INA226AIDGSR：**VS = AX_3V3**（100nF 旁路），A0/A1 接地，地址 0x40，接 I2C0；ALERT 经 10k 上拉 AX_3V3 送 TCA9555 P1.6。
- RS = 5mΩ、1%、≥1W、2512，优选四端；IN+ 接输入侧、IN− 接输出侧，Kelvin 引线从电阻焊盘单独取样；VBUS 接 12V_MAIN。
- IN+、IN−、VBUS 的绝对额定电压与 VS 无关（按手册核对），因此 INA226 随 AX7010 开关不影响主电路；AX7010 断电时只是暂停测量。

`5A：压降 25mV、损耗 0.125W；Current_LSB = 0.25mA，CAL = 0.00512 / (0.00025 × 0.005) = 4096`

采样监测用于记录、预算和告警，不代替短路保护，也不能完整反映打印头的快速脉冲。

## 5  3.3V 电源与电源域

| 网络 | 来源 | 供电对象 | 何时有电 |
|---|---|---|---|
| AX_3V3 | AX7010 J11-39/40（板上 +3.3V，**不是 Bank35 VCCIO**），经 600Ω 磁珠 + 10µF | TCA9555、INA226、DS3231、I2C0 上拉、EC11/K1 上拉、74LVC244A、74LVC2G17、LIGHT_OK 上拉（合计 <50mA） | AX7010 上电时，略早于 VCCIO |
| 3V3_SENS | 5V_AUX → TPS7A2033PDBVR，**EN 由 AX_3V3 经 100k/1µF 延时，并用 BAT54 快速放电** | TOF、IMU、SHT40、ADXL355、J28、I2C1/I2C2 上拉 | AX_3V3 建立后按 RC 延时开启，约 30ms 为估算 |
| 3V3_D | 5V_AUX → TLV1117LV33DCYR | SD 卡、TLV3011B、MISO 选通缓冲、打印机发送缓冲 | 载板上电即有 |
| Nano 3V3 | Nano 自身稳压 | 只供 Nano 自身，不对外 | — |

各路 3.3V **不并联**。

- **TLV1117LV33DCYR**：IN（3）接 5V_AUX，GND（1）接地，OUT（2）及散热片为 3V3_D；输入 10µF、输出 22µF X7R（允许陶瓷电容）；输入上限 5.5V。负载约 150mA，损耗约 0.26W。
- **TPS7A2033PDBVR**：IN（1）接 5V_AUX，GND（2），EN（3）经 100kΩ 接 AX_3V3、对地 1µF；BAT54 阳极接 EN、阴极接 AX_3V3，用于快速放电。约 30ms 是上电估算，不保证 Bank35 时序；正常上下电时实测确认，NC（4）悬空，OUT（5）为 3V3_SENS；输入、输出各 2.2µF，有效输出 ≥1µF；按连续 120mA、短时 200mA 规划。P 版本带输出主动放电。
- **AX_3V3**：40P 排线的 39、40 脚并联取电，绿色指示灯（串 2.2k）。只供与 FPGA 引脚直连的小电流器件：静态约 5mA；TCA9555 每打开一路输出约多 3.3mA（1k 下拉），全部打开时合计仍 <50mA。AX7010 的 3.3V 由 3A 的 TLV62130 提供，余量充足。

**Nano 供电**：12V_MAIN → 0.5A PTC → Nano VIN，旁放 10µF/25V + 100nF。VIN 推荐 6–21V，按稳定 12V 适配器供电设计。SMBJ13A 是瞬态抑制器，不将其视作 VIN 持续过压稳压器。VBUS 不接载板 5V。

## 7  12V 负载驱动

### 7.1 补光灯（两路相同）

| UCC27517DBVR 引脚 | 连接 |
|---|---|
| 1 VDD | 5V_AUX，1µF + 100nF |
| 2 GND | GND |
| 3 IN+ | LEDx_PWM（J11-3 / J11-4）经 100Ω；对地 2.2k 下拉（理由见 8.3） |
| 4 IN− | LED_EN（两颗驱动器的 IN− 并联；芯片内部有到 VDD 的上拉） |
| 5 OUT | 经 10Ω 接 AOD4184A Gate；Gate–Source 100k |

- AOD4184A：Drain 接灯带负端，Source 接地；灯带正端经分支保险丝（0.75A 灯带从约 1.25A 开始选）接 12V_MAIN；SS54 阳极接 LED−、阴极接 LED+。输出 J7 / J25（5.08 2P）。
- **补光自锁按钮**：J29（GH 2P）1 脚 LED_EN、2 脚 GND。LED_EN 经 10k **上拉到 5V_AUX**、100nF 对地，接两颗 UCC27517 的 IN−。按钮闭合 → LED_EN 低 → 允许；断开 → LED_EN 为 5V → 驱动器输出被强制为低。按钮只走约 0.5mA，选允许小电流信号使用的自锁按钮。
- **LED_EN 只留在 5V 域**：UCC27517 的 IN− 内部上拉到 VDD（5V），若接回 AX_3V3 会形成 5V → AX_3V3 的电阻通路。按钮状态改由 Q10（2N7002）读取：Gate 接 LED_EN，Source 接地，Drain 为 LIGHT_OK（10k 上拉 AX_3V3）→ TCA9555 P0.0。按钮闭合时 Q10 截止，LIGHT_OK = 高 = 允许。AX7010 断电时 Q10 漏极上拉也无电，不倒灌。
- UCC27517 输出 = IN+ 且非 IN−：按钮断开必关灯（硬件）；PL 未配置或重载 Overlay 时 IN+ 被下拉也关灯；AX7010 断电时 AX_3V3 为 0，IN+ 同样为低。
- 测振默认 100% 恒亮；PWM 调光（约 20kHz）需实测条纹和帧间亮度波动。12V 输出只用于已带限流的灯带。

### 7.2 打印机高边开关

```tcl
12V_MAIN → 分支保险丝（约 2.5–3A，按实测定型）→ AO4407A Source；Drain → 12V_PRN → J13-1
Gate–Source 47kΩ + BZT52C12（阴极接 Source）；Gate 经 10kΩ 接 2N7002（Q4）Drain，Source 接地
Q4 Gate：100Ω 接 PRN_PWR_EN（TCA9555 P0.6），1k 下拉
J13 附近：470µF/25V + 1µF + 100nF
```

Vgs ≈ −12 × 47/57 ≈ −9.9V。Gate–Source 可预留 100–330nF 焊位放缓开通，但这不是精确限流。打印机地线始终与系统相连。

### 7.3 报警灯、蜂鸣器、风扇与继电器

- 6 路 AO3400A 低边开关：Gate 串 100Ω、**1k 下拉**，由 TCA9555 P1.0–P1.5 驱动。AO3400A 的 Vth 最小约 0.65V，TCA9555 输入态的内部上拉在 10k 上可能产生约 0.8V，故取 1k（约 0.1V）。负载正端接 12V（继电器线圈接 5V_AUX），负端接 Drain。
- J9（5.08 6P）：+12V、R−、Y−、G−、BZ−、FAN−；使用 12V 成品限流灯和 12V 有源蜂鸣器。风扇、蜂鸣器加 SS14 续流（阴极接 12V）。
- 继电器 RLY1（可选）SRD-05VDC-SL-C：线圈并 1N4007（阴极接 5V），触点 NO/COM/NC 经 J10 引出，只作低压干接点联动，不描述成安全停机系统。
- 独立三色灯跟随测量判级；红色报警在 K1 确认静音后不清除，条件解除后才更新。

## 8  跨电源域接口

### 8.1 接收缓冲 U9（74LVC244A，VCC=AX_3V3，两组 /OE 接地）

| 输入（A） | 来源 | 输出（Y）→ 1k → J11 |
|---|---|---|
| 1A1 | Nano D2（TX） | ESP_RXD → J11-20 |
| 1A2 | Nano D4（RTS） | ESP_CTS → J11-22 |
| 1A3 | Nano D6（IRQ） | ESP_IRQ → J11-23 |
| 1A4 | J13-4 HOST_RX（打印机发送） | PRN_RXD → J11-25 |
| 2A1 | J13-2 CTS（100k 上拉 AX_3V3，断电时为“忙”） | PRN_CTS → J11-26 |
| 2A2 | J24-3 转速（1k + 100pF；开集电极时 10k 上拉 AX_3V3） | TACH_IN → J11-15 |
| 2A3 | PFAIL_N | PFAIL_N → J11-9 |
| 2A4 | 接 GND | 不接 |

固定选择 Nexperia 74LVC244APW,118（施密特输入）：输入 5.5V 容限、带 Ioff，打印机的 5V 电平可以直接接入；缓冲器由 AX_3V3 供电，AX7010 断电时一起断电。冷启动时 AX_3V3 比 Bank35 VCCIO 早建立，缓冲器输出此时可能已为高，因此 **7 路输出各串 1kΩ 再进 J11**（RN1–RN3 为独立排阻，剩余通道供编码器和传感器中断使用），把经 FPGA 钳位二极管的电流限制在约 3mA 量级；921600bps 的 UART 需结合波形验证。每颗 100nF。

### 8.2 FPGA 发往其他电源域

- **ESP_TXD（J11-19）→ Nano D3、ESP_RTS（J11-21）→ Nano D5**：各串 1kΩ。Nano 与载板同由 12V 供电，串阻限制上下电过程中的信号电流。
- **PRN_TXD（J11-24）→ 打印机**：SN74LVC1G125（VCC=3V3_D），A 端 10k 上拉 AX_3V3（PL 重配置时保持空闲高），Y 端串 100Ω 到 J13-3；/OE 10k 上拉 3V3_D，由 **PRN_COM_EN（TCA9555 P0.7）**经 Q7（2N7002，Gate 1k 下拉）拉低使能，与打印机电源分开控制：打印机上电并就绪后才打开发送，关电前先关闭，避免 3.3V 空闲高经 TX 灌入正在上电或已断电的打印机。J13-3 不加板上上拉。
- **LED1/LED2_PWM、WS_DATA**：按指定 UCC27517 和 SN74AHCT1G125 的输入结构连接，保持现有单级接口；输入端 2.2k 下拉保证 PL 未配置时为低。

### 8.3 PL 重配置时的行为

| 输出 | PL 未配置 / 重载 Overlay 时 |
|---|---|
| 补光 PWM | 2.2k 下拉 → 灯灭 |
| WS_DATA | 2.2k 下拉为低 → 不刷新，保留最后颜色；正常重配置前软件先写灭 |
| PRN_TXD | 10k 上拉 → 空闲高，不会发出乱码 |
| TCA9555 控制的负载 | 寄存器保持原状态；软件在卸载 Overlay 前先关闭打印、报警输出 |
| I2C、SPI | I2C 由外部上拉保持高；SPI 片选由模块上拉保持未选中，SCLK/MOSI 不按有上拉处理 |

> **下拉取值**　Zynq PL 在配置期间的 I/O 状态取决于 PUDC_B 接法：若 AX7010 把 PUDC_B 接低，配置期间全部 PL 引脚会有弱上拉（约 90–330µA，相当于 10–37kΩ），100k 下拉压不住。因此补光 PWM 与 WS_DATA 的下拉取 2.2k：最坏情况下约 0.6V，低于 UCC27517 与 AHCT 的低电平阈值；FPGA 输出高电平时只多 1.5mA。PUDC_B 接法以 AX7010 原理图为准，若接高（无上拉）可放宽到 10k。

## 9  热敏打印机接口 J13（PH2.0×5P）

| J13 针 | 打印机定义 | 载板连接 |
|---|---|---|
| 1 | VIN（整机电源+） | 12V_PRN |
| 2 | CTS（高忙 / 低允许） | → U9 2A1 → PRN_CTS |
| 3 | TX（主机发送） | PRN_TXD → U11 → 100Ω → 此针 |
| 4 | RX（主机接收） | 此针 → U9 1A4 → PRN_RXD |
| 5 | GND | 系统 GND |

- 第 3、4 针的 TX/RX 已按主机方向定义，**不再交叉**。丝印 VIN / CTS / HOST_TX / HOST_RX / GND，核对连接器朝向与实物 1 脚。
- 连接器：JST S5B-PH-K-S（卧插）或 B5B-PH-K-S，配 PHR-5，间距 2.0mm。PH 额定 2A@AWG24：**VIN 只走 1 根针**，实测打印峰值若超过约 1.5A 或触点温升明显，应另加 2P 电源线分流或换连接器。
- 打印时序：停止采集、关补光 → PRN_COM_EN=0 → PRN_PWR_EN=1 → 等待厂家启动时间且 CTS 为低 → PRN_COM_EN=1 → 发送；结束：确认打印完成 → PRN_COM_EN=0 → PRN_PWR_EN=0。发送中监视 CTS，高时暂停并设超时；断电状态下不采信 CTS。“打印完成”要按厂家说明确认，不能只凭 CTS 低或 UART 空判断。

## 10  屏幕、旋钮、按键与状态灯

### 10.1 屏幕

- AX7010 HDMI → 屏幕 HDMI；AX7010 USB HOST → 屏幕 Touch（AX7010 的 J5、J6 跳线帽插上为 HOST 模式）；载板 J4 → 屏幕 Power Only。
- HDMI 工程设 1024×600，并核对 EDID 与实际时序。先在 AX7010 上验证 Linux USB 触摸驱动与坐标。

### 10.2 EC11 与 K1

- EC11（带按压）：A、B 各 10k 上拉 AX_3V3、1k 串联、10nF 对地，经 SN74LVC2G17（U12，VCC=AX_3V3），输出各串 1k（RN3）送 J11-17、J11-18，PL 按合法正交状态计数。
- ENC_SW、K1：同样的 RC 电路，直接接 J11-16、J11-5，PL 同步后 10–20ms 消抖。
- 旋转：缩放（PL 缩放器或 PS 重采样实现，VDMA 裁剪本身不是放大）；按下：恢复 1×；触屏点击：设定缩放中心。
- K1 短按：报警确认 / 静音；长按 3s：请求安全关机，完成后手动断总开关。

### 10.3 状态灯（五颗 WS2812）

WS_DATA（J11-6）→ 74AHCT1G125（U13，VCC=5V_AUX，/OE 接地，输入 2.2k 下拉）→ 330Ω → 第一颗 DIN（10k 下拉）。每颗 100nF，面板入口 47–100µF，软件限制亮度。

| 灯 | 显示 |
|---|---|
| 1 系统 | 黄：初始化；绿慢闪：软件心跳；红：故障 |
| 2 网络 | 蓝闪：连接中；绿：已连接；黄：断开 / 失败 |
| 3 测量 | 灭：待机；绿闪：采集；蓝：计算；黄：测量条件不满足（如补光未允许） |
| 4 外围 | 蓝短闪：读卡；黄闪：打印；绿短亮：成功；红闪：失败 |
| 5 报警 | 低亮绿：正常；黄：预警；红：报警 |

状态由 PS 统一管理，Nano 经 UART 上报网络 / NFC / SD 状态，PL 产生时序。故障优先于进行中，进行中优先于短暂成功；心跳需持续更新，不能用残留的绿色证明系统健康。

### 11.1 供电与安装

## 12  外接传感器

所有传感器由 3V3_SENS 供电（TPS7A2033，EN 由 AX_3V3 经 100k/1µF 延时约 30ms），设计意图是延后传感器上电，实际是否晚于 Bank35 VCCIO 建立须实测；AX_3V3 下降时 BAT54 加速 EN 放电。开漏返回按上拉连接，推挽返回各串 1kΩ 后接 J11。按连续 120mA、短时 200mA 预算；未来加装热成像时重新核算总电流和 LDO 温升。

### 12.1 TOF  J14（GH 6P）

| J14 脚 | 模块丝印 | 连接 |
|---|---|---|
| 1 | VIN | 3V3_SENS |
| 2 | GND | GND |
| 3 | SCL | I2C1_SCL |
| 4 | SDA | I2C1_SDA |
| 5 | GPIO1 | TOF_INT → J11-7（模块自带上拉） |
| 6 | XSHUT | XSHUT_OD：Q8（2N7002）Drain，Gate 接 TOF_DISABLE（TCA9555 P0.4）、1k 下拉 |

- XSHUT 只拉低或释放，高电平由模块自身上拉提供；TCA9555 上电为输入态 → Q8 截止 → TOF 默认工作。
- 黑色六针 VL53LXX-V2 模块的芯片可能是 VL53L0X 或 VL53L1X，地址都为 0x29。**上电后读型号寄存器确认**：VL53L0X 的 0xC0 应为 0xEE；VL53L1X 的 0x010F–0x0110 应为 0xEA、0xCC。两者驱动不同，不能只凭商品标题判定。
- 用途：测相机到被测面的距离，辅助像素位移到毫米的比例换算；换算系数还与镜头焦距、视角和被测面倾斜有关，需用标定板或已知位移标定。

### 12.3 参考加速度计 ADXL355  J16（GH 8P，可选）

| J16 脚 | 信号 | 连接 |
|---|---|---|
| 1 | 3V3 | 3V3_SENS |
| 2 | GND | GND |
| 3 | SCLK | SPI_SCLK |
| 4 | MOSI | SPI_MOSI |
| 5 | MISO | SPI_MISO |

ADXL355 用 SPI 模式 0，与 IMU 模式不同，PL 的 SPI 主机按片选切换模式。读 DEVID_AD（0x00）应为 0xAD、PARTID（0x02）应为 0xED。用途：贴在被测物上作为对照，验证视觉测振的幅值和频率。不装时 J16 空置，ADXL_CS 由 FPGA 保持高；J16 可作同电压 SPI 扩展口，片选和 DRDY 按所接外设重新定义。

### 12.4 温湿度 SHT40  J17（GH 4P）

1 VIN（3V3_SENS）、2 GND、3 SCL（I2C1_SCL）、4 SDA（I2C1_SDA）。地址 0x44，与 TOF 共用 I2C1。探头放在外壳通风处、远离降压器和补光灯，用于记录测量环境。

### 12.5 I2C2 扩展  J28（GH 4P）

1 3V3（3V3_SENS）、2 GND、3 SCL（I2C2_SCL）、4 SDA（I2C2_SDA），载板 4.7k 上拉。首版不装热成像；以后接 MLX90640（0x33，3.3V 供电版）时核对供电、模块上拉和总线电容，I2C2 从 400kHz 开始，验证后提高到 1MHz。

### 12.6 转速  J24（GH 3P，可选）

1 5V_AUX、2 GND、3 SIG。SIG 经 1kΩ、100pF 对地后进入 U9 2A2（5.5V 容限），输出 TACH_IN → J11-15。开集电极输出的传感器（如霍尔、光电对管模块）焊上 10k 上拉到 AX_3V3 的焊位；推挽输出不焊。用于给旋转设备提供转频参考，与视觉测得的主频对比。

### 12.7 上拉与串阻

- I2C1、I2C2 的 SCL、SDA 各 4.7kΩ 上拉到 3V3_SENS。TOF 模块自带约 10k 上拉，并联后约 3.2k，以 100kHz 起步；400kHz 按线缆电容和实测上升时间确认。
- SPI_SCLK、SPI_MOSI 在载板 FPGA 侧各串 33Ω；共享 SPI_MISO 在 FPGA 附近串 1kΩ，SPI 初始 1MHz，提速前验证边沿与采样时序。
- IMU_INT1、IMU_INT2、ADXL_DRDY 各串 1kΩ；LSM6DSV 中断默认推挽，不能把这些返回信号归为开漏。可利用 RN1–RN3 的剩余三个独立通道。
- IMU_CS、ADXL_CS 的上拉在模块侧，载板不重复加。

## 13  板内管理：TCA9555、DS3231、INA226

### 13.1 总线一览

| 总线 | 电源 / 上拉 | 器件与地址 | 速率 |
|---|---|---|---|
| I2C0（板内） | AX_3V3，4.7k | TCA9555 0x20、INA226 0x40、DS3231 0x68 | 100kHz，验证后 400kHz |
| I2C1（外接） | 3V3_SENS，4.7k | TOF 0x29、SHT40 0x44 | 100kHz → 400kHz |
| I2C2（扩展） | 3V3_SENS，4.7k | 预留（MLX90640 0x33） | 400kHz → 1MHz |
| SPI（外接） | 3V3_SENS | LSM6DSV（IMU_CS）、ADXL355（ADXL_CS） | 1MHz 起，MISO 串 1kΩ |
| UART1 | 跨域，U9 + 1k | Nano ESP32，带 RTS/CTS、IRQ | 921600bps 起 |
| UART2 | 跨域，U9 + U11 | 热敏打印机，TX、RX、CTS | 按打印机，常见 9600/115200 |

三路 I2C、SPI、两路 UART 都用 PL 中的 AXI IP（AXI IIC、AXI Quad SPI 或自写 SPI、AXI UART16550），由 PS 驱动。

### 13.2 TCA9555PWR（U16，0x20）

| 端口 | 网络 | 方向 | 说明 |
|---|---|---|---|
| P0.0 | LIGHT_OK | 入 | 补光按钮状态：经 Q10 反相，高 = 允许（按钮本身直接控制驱动器） |
| P0.4 | TOF_DISABLE | 出 | → Q8 → J14 XSHUT |
| P0.5 | ESP_RESET | 出 | → Q9 → Nano RST，高电平复位 |
| P0.6 | PRN_PWR_EN | 出 | → Q4 → Q3（打印机电源） |
| P0.7 | PRN_COM_EN | 出 | → Q7 → U11 /OE（打印机发送），与电源分开 |
| P1.0–P1.2 | ALM_R / ALM_Y / ALM_G | 出 | → AO3400A → J9 三色灯 |
| P1.3 | BUZZ | 出 | → AO3400A → 蜂鸣器 |
| P1.4 | RELAY | 出 | → AO3400A → 继电器线圈（可选） |
| P1.5 | FAN | 出 | → AO3400A → 风扇（可选） |
| P1.6 | INA_ALERT | 入 | INA226 ALERT，10k 上拉 AX_3V3 |
| P0.1–P0.3、P1.7 | — | 入 | 空闲，保持输入态；走线引到测试焊盘 |

- 引脚：A0、A1、A2 接地；VCC = AX_3V3（100nF）；/INT 10k 上拉 AX_3V3 → EXP_INT_N（J11-10）。
- 上电时全部为输入态（内部约 100k 上拉），所有输出网络各加 **1k 下拉**（内部上拉在 0V 时约 100µA，1k 上只剩约 0.1V，低阈值 MOS 也能可靠关断），保证负载默认关断。软件先写输出寄存器为“关”，再把方向改为输出。
- AX7010 断电时 TCA9555 一起断电，所有输出回到下拉 → 打印机、报警、风扇全部关闭。

### 13.3 DS3231SN（U17，0x68）

| DS3231SN 引脚（SO-16W） | 连接 |
|---|---|
| 1 32kHz | 测试点（开漏，不接上拉） |
| 2 VCC | AX_3V3，100nF |
| 3 INT/SQW | RTC_1HZ → J11-8，10k 上拉 AX_3V3 |
| 4 RST | 测试点（内部上拉） |
| 5–12 NC | 按手册全部接 GND |
| 13 GND | GND |
| 14 VBAT | CR1220 正极（电池座负极接地），无充电电路 |
| 15 SDA / 16 SCL | I2C0 |

- 配置 INTCN=0、RS=00 输出 1Hz 方波；PL 用它校准本地计数器并给数据打秒级时间戳。AX7010 断电时 DS3231 由电池维持走时，SQW 不输出（BBSQW=0）。
- AX7010 板载的 RTC 接在 PL 上，PYNQ 默认不使用；本板 DS3231 在 0–40°C 规格为 ±2ppm，作为整机唯一时间源，开机后由 Nano 的 NTP 校时。

### 13.4 调试口 J27

1×4 排针：AX_3V3、GND、I2C0_SCL、I2C0_SDA。用于逻辑分析仪或外接 USB-I2C 工具检查板内总线，不对外供电。

## 15  连接器总表

### 15.1 选型原则

| 接口类型 | 选型 | 理由 |
|---|---|---|
| 传感器、PN532、面板、扬声器、补光按钮、转速 | **GH1.25 卧贴**（JST SMxxB-GHS-TB 或同规格国产件） | 电流 <1A，带锁扣防振动脱落；卧贴开口朝板边，叠装 AX7010 后仍方便插拔 |
| 热敏打印机 | PH2.0 5P 卧插（JST S5B-PH-K-S） | 与打印机线束一致；VIN 单针，需实测峰值（见第 9 章） |
| 12V 输入、补光、5V_AX、报警输出、继电器 | DC 座 / 5.08 插拔端子 | 电流大或需要锁紧的功率线 |
| 调试口 | 2.54 排针 | 方便接逻辑分析仪、USB-TTL |
| AX7010 | 2×20 牛角座 | 与 AX7010 J11 用 40P 排线直通 |

- GH 单针额定电流按 AWG26 的 1A 规格核对；更细线材另核算。**成品预压线**，双头线选“**同向**”（1 脚对 1 脚）；接模块排针用“GH1.25 转杜邦母头”单头线。
- 全板 GH 座统一 1 脚方向，丝印标 1 脚和信号名；两侧固定脚焊满，插拔时不要横向扳动。

## 18  PCB 布局要点

- **四层板**：L1 器件、信号、功率铜；L2 完整 GND；L3 电源分区及少量信号；L4 信号、辅助铜。
- 输入保护、三路降压、打印机和补光功率输出集中在功率区；J6、缓冲器、TCA9555、RTC 在低噪声区。大电流回流不穿过信号区，数字信号下方不切割 GND。
- TPS5430：输入电容—芯片—续流二极管回路最小；PH 铜面积适量；反馈走线远离 PH、电感；PowerPAD 打散热过孔。
- INA226 的 IN+、IN− 从采样电阻焊盘内侧 Kelvin 引出，两线并行走到芯片。
- Nano 天线端伸出板边或下方挖空；PN532 天线远离金属和功率电感。
- GH 卧贴座统一放在板边、开口朝外；同一束线的座子相邻摆放。
- 12V 主路按 5A 设计铜宽（外层 1oz 约需 3mm 以上，按温升计算核对），过孔成组。
- 测试点：12V_MAIN、5V_AX、5V_LCD、5V_AUX、AX_3V3、3V3_D、3V3_SENS、PFAIL_N、LED_EN、LIGHT_OK、PRN_PWR_EN、PRN_COM_EN、各 I2C、SPI_SCLK、两路 UART。

## 19  首板验证顺序

1. 空板（不插 AX7010 和模块）：验证输入极性、反接保护、静态电流；检查 TVS、保险丝方向。
2. 三路 5V：空载、2A 假负载（2.5Ω ≥20W）下的电压、纹波、启动波形和温升。确认 3V3_D 正常、3V3_SENS 在 AX_3V3 为 0 时关闭。
3. 接 AX7010 + AN5642（不接 J6 排线）：确认 5V_AX 下 AX7010 正常启动、视频与 HDMI 显示正常。
4. 接屏幕供电与 USB 触摸，确认 Linux 识别触摸。
5. 接 J6 排线，**测正常上电、关机和重新上电时序**：示波器同时测 AX_3V3（J11-39，磁珠前后分别测量）、AX7010 的 Bank35 VCCIO（SPX3819 输出电容处）、3V3_SENS 和一路 U9 输出（如 PFAIL_N 在 J11 端），记录 AX_3V3 领先 VCCIO 的时间、VCCIO 建立前 J11 引脚上的电压，并确认 3V3_SENS 在 VCCIO 之后上电。满足 Zynq 输入要求则保持直连；不满足再只对相关路径加使能。
6. 断电与倒灌：**关掉 AX7010 自身开关、载板仍通电时，AX_3V3 应 <0.3V**；同时测 LED_EN（应为 5V 或 0V，与 AX_3V3 无关）。
7. PL 未加载 / 重载 Overlay 时，用示波器看 LED1_PWM、WS_DATA 保持低、PRN_TXD 保持高，补光不闪。
8. 调通 I2C0：TCA9555、INA226（校准电流）、DS3231（1Hz 输出）；确认 TCA9555 上电时所有负载关闭。
9. 调通 TOF（读型号寄存器）、SHT40、IMU（WHO_AM_I）、ADXL355；验证 SPI 两种模式切换。之后做 TOF 距离与像素比例、IMU 与图像位移的标定。
10. 调通 Nano UART（含流控）、SD、PN532；**交替访问 SD 与 PN532，确认 MISO 选通有效**；语音播放。
11. 补光：按钮断开时 PWM 为高也不亮，LIGHT_OK 读为 0；闭合后读为 1，验证 100% 与 PWM 调光，观察相机画面条纹。
12. 打印机：按“上电 → 就绪 → 开通信 → 打印 → 关通信 → 断电”验证，确认 PRN_COM_EN=0 时 J13-3 为高阻；测走纸、普通文本和大面积黑色打印的电流与 J13 温升；验证 CTS 流控。
13. 整机组合负载：相机 + 屏幕 + 补光 + 语音，与“关补光后打印”，观察 12V、5V_AX 是否跌落、是否复位；验证 PFAIL 阈值。

## 20  相机测振能力约束与待确认事项

### 20.1 相机约束

AN5642 可以做视觉运动显示和低频测振，但**载板外设不会提高相机的有效采样频率**。ALINX 例程常见 720P、30fps；30fps 的奈奎斯特上限是 15Hz，60fps 对应 30Hz，实际测量应留余量。更高帧率要在所选分辨率、格式和 FPGA 工程中实测。

- 测量时固定曝光、增益和补光亮度；记录每路 VSYNC 和丢帧。
- IMU 数据就绪、ADXL355 DRDY、RTC 1Hz 和相机帧用同一 PL 计数器打时间戳；不把 VSYNC 边沿等同于所有像素的曝光时刻（滚动快门）。
- 两颗 OV5640 不保证同步曝光，分别记录时间戳。

## 22 绘图补充：逻辑器件明确引脚与电阻通道

SN74LVC2G17DBVR（U12）：1=1A、2=GND、3=2A、4=2Y、5=VCC、6=1Y；VCC 接 AX_3V3，去耦 100nF。不要按普通六针双门逻辑封装猜测引脚。

INA226AIDGSR（U1，VSSOP-10）：1=A1、2=A0，均接地；3=ALERT、4=SDA、5=SCL、6=VS、7=GND、8=VBUS、9=IN−、10=IN+。VS 接 AX_3V3，VBUS 接 12V_MAIN，IN+/IN− 分别 Kelvin 连接采样电阻输入/输出。

TCA9555PWR（U16，TSSOP-24）：1=/INT、2=A1、3=A2、4–11=P0.0–P0.7、12=GND、13–20=P1.0–P1.7、21=A0、22=SCL、23=SDA、24=VCC；A0/A1/A2 均接地，VCC 接 AX_3V3。

SN74LVC1G125DBVR（U11）及 SN74AHCT1G125DBVR（U13）：1=/OE、2=A、3=GND、4=Y、5=VCC；U11 接 3V3_D，U13 接 5V_AUX。

SN74LVC2G125DCUR（U14）：1=/1OE、2=1A、3=2Y、4=GND、5=2A、6=1Y、7=/2OE、8=VCC；VCC 接 3V3_D、100nF 去耦。

RN1–RN3 均为四个相互独立的 1kΩ 电阻组成的排阻，不能用共端排阻。总计 12 个通道：U9 返回 7 路、U12 编码器返回 2 路、IMU_INT1/INT2 和 ADXL_DRDY 返回 3 路。SPI_MISO 另用一个独立 1kΩ 电阻。

前面板 RC 明确接法：AX_3V3 → 10kΩ → 按键/编码器触点节点，触点闭合接 GND；节点 → 1kΩ → 输入滤波节点，滤波节点 10nF 对地。编码器 A/B 的滤波节点接 U12 输入，其输出另串 1kΩ 再到 J11。K1 和 ENC_SW 滤波节点直接到 J11。

BAT54 选具体单二极管 SOT-23 型号，符号阳极/阴极按该品牌手册对应焊盘，剩余 NC 不连接。正文描述的是电气极性，不能把封装未用脚当作接地脚。
