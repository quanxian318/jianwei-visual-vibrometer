# 作品视频

比赛作品视频的素材、渲染脚本和样片。成片要求：3 分钟内，MP4，H.264，300 MB 以内。

## 目录

- `素材/实拍`：整机连线、两块自研 PCB、主载板接线、外壳内部装配、外壳机盖、AX7010 实拍图；开场钩子 `钩子_电机铝片散斑.mp4` 及原理动画用的静帧 `钩子_静帧.png`。
- `脚本/render_part1.py`：渲染"上电"之前的部分，依次为钩子、标题、应用背景、测量原理、硬件与外设（整机三组外设、外壳内部、机盖、主载板、接口、前面板、AX7010）、系统架构、PL 硬件设计，共约 85 秒。
- `输出/上电前_样片.mp4`：当前样片，1920×1080、30 fps、H.264 High + AAC。

## 渲染

在 WSL 中运行，使用已有的 ffmpeg、Pillow、numpy 和 Windows 字体（Noto Sans SC、Noto Serif SC、Bahnschrift）：

```bash
cd 07_作品视频/脚本 && python3 render_part1.py
```

加 `--stills 12 40 --still-dir 目录` 只导出指定秒数的静帧，用来检查版式；`--hook` 可换开场片段，默认取钩子视频前 5 秒并保留原声。

## 画面依据

- 算法与分工按 2026-11-03 代码包 `docs/current/算法与状态.md`：测点最多 12 个（默认 4 列 3 行）、4 个背景参考点，25×25 模板亚像素跟踪，128 帧窗、Hann FFT，停机基线 3 倍门限；双目深度为 PS 软件后端，PL 负责双路视频、HDMI、PDM 接收、灯光 PWM 和打印 UART。
- PL 资源与时序：同一代码包中 printer_uart 工程的 Vivado 2025.2 实现报告（`ax7010/vivado/current/reports_original_build/`），画面只显示百分比，BRAM 30.5/60 块折算为 50.8%。
- 钩子结尾的 10.84 Hz、0.142 mm 取自 `05_验证资料/板端报警/板端验证.json`（2026-10-31 板端记录），改为本片实测值时修改脚本里的 `HOOK_RESULT`。
- 接口位号与外设对应：`04_使用指南/整机装配_逐引脚接线与模块互连.md`。
- 机盖部件按作者说明标注：左上为三色声光报警灯和 NFC，麦克风口在前面板右下角，四个按键从左到右为风扇、警报灯、照明、电源。
- 外设标注按设计用途描述；温湿度、测距目前界面为固定显示，不代表传感器实测。
- 测量原理里的放大格、波形和频谱是示意图，不是实测数据。
