# 作品视频

比赛作品视频的素材、渲染脚本和成片。成片要求：3 分钟内，MP4，H.264，300 MB 以内；视频中不出现校徽。

## 目录

- `素材/实拍`：整机连线、两块自研 PCB、主载板接线、外壳内部装配、外壳机盖、AX7010 实拍图，组装完成后的整机亮灯照片（低角度、正面、斜俯视）与机盖俯拍界面；开场钩子 `钩子_电机铝片散斑.mp4` 及原理动画用的静帧 `钩子_静帧.png`。`整机_正面亮灯.jpg` 右上角有路人，使用时裁掉。
- `素材/实测`：2026-11-04 02:05 同一次测量的三段录像，都截成对应全景原片 2.5–70 s（素材内时间 = 全景原片时间 − 2.5 s）。`全景_测量过程.mp4` 为 iPhone 横拍，HDR 原片按 hable 色调映射转为 SDR；`屏幕_测量过程.mp4` 为手机拍摄的 7 寸屏，已顺时针转 90° 让界面正向；`APP_测量过程.mp4` 为手机 APP 录屏，无声。对齐依据：屏幕原片比全景早 1.0 s（报警灯亮 37.2 / 38.2 s），APP 原片比全景晚 3.4 s（开始测量 31.8 / 28.4 s）。
- `素材/配音`：旁白音频与 `配音记录.json`（文本、文件、时长、合成参数），由 `脚本/synth_voice.py` 生成。
- `素材/外部/工业设备_压力表振动.mp4`：应用背景用的工业设备实景，机器上的压力表随设备轻微抖动，来自 [Pexels 视频 40481917](https://www.pexels.com/video/industrial-pressure-gauges-in-action-40481917/)，按 Pexels 许可免费使用、无需署名，素材无原声。
- `素材/APP/电脑端_总览.png`：APP web 界面演示模式在 1440×900 窗口下的截图，代表电脑端；手机端直接用 `05_验证资料/APP验证/构建验证/ios_home.png`。
- `脚本/render_video.py`：渲染成片，依次为钩子、标题、应用背景（故障风险，接触式传感器、激光测振仪与见微对比）、测量原理、硬件与外设、系统架构、PL 硬件设计、上电实测（一镜到底）、实测结果、总结、结尾，共 179.6 秒。
- `输出/见微_作品视频.mp4`：成片，1920×1080、30 fps、H.264 High + AAC；设了码率上限，文件保持在 100 MB 以内。

## 配音

旁白用百度语音合成，发音人度怀安（大模型音库 per=4195，语速 6），文本由脚本里的字幕换算（Hz、mm 读作赫兹、毫米）；标为“设备语音”的两句不配旁白，保留设备原声。密钥只从环境变量读取：

```bash
cd 07_作品视频/脚本 && BAIDU_API_KEY=... BAIDU_SECRET_KEY=... python synth_voice.py
```

文本和参数没变的句子沿用已有音频。渲染时每句旁白接在上一句之后，字幕显示到该句结束，旁白比画面长时场景自动延长；旁白响起时压低钩子原声和现场声。`python3 render_video.py --plan` 列出各场景实际时长与旁白时间，并标出压到设备原声的句子。

## 渲染

在 WSL 中运行，使用已有的 ffmpeg、Pillow、numpy 和 Windows 字体（Noto Sans SC、Noto Serif SC、Bahnschrift）：

```bash
cd 07_作品视频/脚本 && python3 render_video.py
```

加 `--stills 12 40 --still-dir 目录` 只导出指定秒数的静帧，用来检查版式；`--hook` 可换开场片段，默认取钩子视频前 4.6 秒并保留原声。

## 画面依据

- 上电实测为一镜到底：全景、7 寸屏、手机 APP 三路画面始终同时在屏，共用全景原片时间轴，只按阶段调整大小、位置和变速（基线 3×、测量 2×、结果后段 3×、收据 0.5×，变速时右上角标出），不剪切。右上角现场时间按记录开始测量时刻 02:05:10.6 对应全景原片 28.4 s 推算；屏幕画面的取景框跟随手持机位漂移（按界面位置检测结果插值），收据阶段卡片转 90° 使收据正向。
- 现场原声只保留原速段：基线完成语音“停机基线已采集，请开始测量”和随后的电机声，报警段的蜂鸣器与“振动异常，请及时检查设备”语音；快放、慢放段静音。
- 算法与分工按 2026-11-03 代码包 `docs/current/算法与状态.md`：测点最多 12 个（默认 4 列 3 行）、4 个背景参考点，25×25 模板亚像素跟踪，128 帧窗、Hann FFT，停机基线 3 倍门限；双目深度为 PS 软件后端，PL 负责双路视频、HDMI、PDM 接收、灯光 PWM 和打印 UART。
- PL 资源与时序：同一代码包中 printer_uart 工程的 Vivado 2025.2 实现报告（`ax7010/vivado/current/reports_original_build/`），画面只显示百分比，BRAM 30.5/60 块折算为 50.8%。
- 钩子结尾和实测结果页的数值取自 `05_验证资料/板端实测/record.json`（2026-11-04 02:05）：视觉主频 19.95 Hz、麦克风包络 19.93 Hz、峰峰值 0.209 mm（试验标定）、12/12 测点超过停机基线、452 帧无丢帧；柱状图为 12 个测点的 gate_ratio。换用新测量时同步修改脚本里的 `HOOK_RESULT`、`LIVE_DATA` 和 `LIVE_GATES`。
- 接口位号与外设对应：`04_使用指南/整机装配_逐引脚接线与模块互连.md`。
- 机盖部件按作者说明标注：左上为三色声光报警灯和 NFC，麦克风口在前面板右下角，四个按键从左到右为风扇、警报灯、照明、电源。
- 架构图中的 APP 按 `04_使用指南/APP使用与开发.md`：Android、iOS、Windows 共用一套界面，可局域网直连 AX7010，也可连 ESP32 热点；架构图里的截图为演示模式数据，实测段为真机录屏。
- 外设标注按设计用途描述；温湿度、测距在本次记录中没有有效读数。
- 测量原理里的放大格、波形和频谱是示意图，不是实测数据。
