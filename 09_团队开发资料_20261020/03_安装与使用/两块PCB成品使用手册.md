# 视觉测振仪：主载板与前面板成品使用及开发指南

团队交付版：2026/10/20。硬件以本包原生工程及逐引脚网表为准；外接模块按用户最终确认清单。

本指南面向设备使用者、装配维护人员以及负责AX7010、FPGA、Nano和应用软件的开发者。正文说明成品的连接和操作，技术附录给出开发接口。软件通信接口按本包协议V1实施；具体设备的固件版本、校准编号、测量频带、打印机参数和网络配置，以随设备填写的《设备配置单》为准；真实AXI地址和Linux设备节点由配套Vivado/设备树填写，不能从网络名推断。

文中“主板J101”是12V入口，“前面板J101”是10针板间接口，属于两个独立PCB，位号必须连同板名一起识别。“开关关闭”指触点断开，不按按钮帽高低判断。

## 1. 设备组成与功能

| 部分 | 作用 |
|---|---|
| AX7010 | 运行主应用、视觉处理、数据管理和HDMI界面；PL负责外围时序及事件采集 |
| AN5642相机 | 获取被测物的图像，连接AX7010的J10 |
| 主载板 | 把12V分配给主控、屏幕、补光和外设，提供传感器、打印及报警接口 |
| 前面板小板 | 一个EC11旋钮、一个操作按键、五颗彩色状态灯；没有独立MCU |
| Nano ESP32 ABX00083 | 网络、NFC读卡、辅助SD卡管理和语音播放 |
| 7英寸HDMI电容触摸屏H款 | 显示1024×600界面，USB传递触摸事件 |
| ToF、相机IMU、温湿度模块 | 分别提供距离参考、相机运动参考及环境记录 |
| 可选参考加速度计、转速探头 | 用于结果对照和旋转机械转频参考 |
| 热敏打印机、组合报警灯、喇叭 | 输出纸质结果、声光提示及中文语音 |

热成像只保留I2C扩展能力；没有安装对应模块和软件时，设备不提供热成像功能。设备没有激振器驱动、外部激振功放或继电器干接点接口。

视觉测量的频率范围、位移范围和误差取决于有效帧率、曝光、视场、安装、标定及算法。不能把相机标称帧率、ToF量程或参考传感器带宽直接当作整机测量指标。

## 2. 操作部件与标识

| 部件 | 操作及效果 |
|---|---|
| SW101 总电源 | 自锁，接通或切断整机12V输入正极；属于硬断电 |
| SW301 补光允许 | 自锁，闭合允许两路补光，断开强制关闭两路补光 |
| SW302 外部声光允许 | 自锁，控制外壳组合三色灯及其蜂鸣器的公共12V供电 |
| SW303 风扇允许 | 自锁，控制风扇正极；闭合后风扇仍受软件控制 |
| ENC101旋钮 | 旋转调整显示缩放；按压恢复1×；不直接改变振动标定比例 |
| 前面板K101 | 短按确认报警并静音；长按约3s请求系统安全关机 |
| 触摸屏 | 设置测点、采集条件、结果显示和打印等应用功能 |

四只自锁开关安装在机壳上，通过螺母固定；旋钮、K101及五颗状态灯在前面板小板上。开关面板的ON/OFF标记必须对应实测触点状态。

### 2.1 硬件开关与软件控制的关系

“允许”不等于“负载已经运行”。补光只有硬件允许且软件输出PWM时才会亮；外部声光灯和风扇只有各自开关接通且软件打开对应MOS时才工作。

SW302不切断前面板五颗状态灯，也不切断J601的语音喇叭。K101静音用于停止蜂鸣/语音提示，不清除正在持续的报警条件和红色报警显示。报警记录由软件保留。

SW301的允许状态可由软件读取；SW302、SW303没有独立位置反馈，界面只能显示软件请求，不能据此保证外部开关已闭合或负载实际动作。重新闭合SW302/SW303时，负载可能立即恢复当前软件请求的状态。

### 2.2 带灯自锁按钮

按钮灯用于显示总电源接通或某一路硬件允许，不作为负载电流、网络或测量健康指示。按钮必须把灯脚和触点区分清楚。

| 按钮 | 灯的规格 | 灯正端 | 灯负端 |
|---|---|---|---|
| SW101总电源 | 内置限流的12V灯，灯脚独立 | J102-2，12V_PROTECTED | J306-2，GND |
| SW301补光允许 | 内置限流、支持5V的灯，灯脚与触点独立 | J306-1，5V_AUX | J305-1，LED_EN |
| SW302外部声光允许 | 内置限流的12V灯，灯脚独立 | SW302之后的ALARM_EXT_12V | J306-2，GND |
| SW303风扇允许 | 内置限流的12V灯，灯脚独立 | SW303之后的FAN_EXT_12V | J306-2，GND |

SW301闭合把LED_EN拉低，5V指示灯随之点亮；开关断开时LED_EN上拉到5V，灯两端近似同电位而熄灭。J305不得接12V。J306只有5V与GND，没有12V输出；其3/4号机械焊脚不是额外线束触点。按钮内部灯跨接两个开关极的款式，不直接套用这张独立灯脚接法。

## 3. 电源、线缆和整机安装

### 3.1 电源规格

使用固定配套的稳压12V、5A适配器，插头5.5×2.5mm、内正外负，接主板J101。整机输入额定60W，软件采用采集与打印错峰的负载策略。

| 电源轨/接口 | 用途 |
|---|---|
| 12V_MAIN | 经过总开关及电流取样后的12V母线 |
| 5V_AX / J201 | AX7010专用5V输出 |
| 5V_LCD / J501 | 屏幕Power Only供电 |
| 5V_AUX | NFC、语音、前面板灯和驱动等辅助电路 |
| NANO_VIN | 12V_MAIN经F201供给Nano VIN |
| 3V3_D | SD、缓冲及掉电比较等常电逻辑 |
| 3V3_SENS | 外部传感器3.3V，受AX7010电源域控制 |
| AX_3V3 | 从AX7010 J11-39/40取出，经磁珠处理的小电流逻辑电源 |

AX_3V3、3V3_D、3V3_SENS与Nano自身3V3输出是不同电源，不能并联。AX_3V3是AX7010板上3.3V，不是直接引出的Bank35 VCCIO。

### 3.2 AX7010、相机和屏幕接线

1. 主板J201用USB-A公头转DC5521公头的5V直通电源线，接AX7010原电源座。建议电源芯线AWG20或更粗、长度不超过20cm，并满足实际电流。
2. 主板J801与AX7010 J11用2.54mm间距、2×20针IDC母头直通排线连接；1对1直到40对40，长度不超过15cm。
3. 排线红边对应两端1脚标记；按实际针号和通断确认，不按照片左右或商品“同向/反向”名称猜测。
4. AN5642接AX7010 J10。J10和J11承担不同任务，不能互换。
5. AX7010 HDMI连接屏幕HDMI；AX7010 USB HOST连接屏幕Touch；主板J501连接屏幕Power Only。J501没有USB数据。
6. AX7010自身电源开关置于ON，整机日常电源由SW101控制。铜柱用于固定两板，40P排线用于信号连接。

整机入口是12V/DC5525，AX7010电源口是5V/DC5521。J801-2按本设计不连接AX7010的5V，以独立电源线供主控。

### 3.3 前面板线束

主板J502与前面板J101使用GH1.25-10P线束，电气针号逐针直通，推荐15–30cm。JST配套线端使用GHR-10V-S与匹配压接端子；成品线也必须验证针序。

| 针号 | 功能 | 主板端网络 | 前面板端连接 |
|---|---|---|---|
| 1 | LED供电 | 5V_AUX | 五颗灯VDD与入口电容正端 |
| 2 | 地 | GND | 地平面 |
| 3 | NC，保留脚 | AX_3V3 | 未连接保留脚 |
| 4 | 地 | GND | 地平面 |
| 5 | 编码器A | ENC_A_RAW | ENC101 A触点 |
| 6 | 编码器B | ENC_B_RAW | ENC101 B触点 |
| 7 | 旋钮按压 | ENC_SW_RAW | ENC101按压触点 |
| 8 | 操作按键 | KEY_K1_RAW | K101触点 |
| 9 | LED数据 | WS_DATA_5V | HL101 DIN |
| 10 | 地 | GND | 地平面 |

原始触点都是闭合接地。上拉、RC和A/B施密特整形在主板，小板不重复加上拉。小板3脚不能用于LED供电。

### 3.4 外部负载和探头安装

补光灯、打印机、喇叭及传感器的插拔在断电时进行。主板MOS低边控制的“负端”是开关节点，不等于固定GND，不能绕接到机壳地。

相机和IMU刚性固定在同一支架；参考加速度计固定在被测物上。NFC天线靠近可刷卡的非金属外壳区域，温湿度模块放通风处并远离降压器和补光热源。风扇气流不应使相机支架或被测薄片产生额外振动。

## 4. 开机、测量与关机

### 4.1 开机

1. 确认相机、屏幕、前面板和本次需要的探头线束已接牢，语音卡在J603内，打印机装好配套纸张。
2. SW301补光允许先关闭；按需要打开SW302外部声光允许与SW303风扇允许。
3. 接入12V适配器，接通SW101。等待屏幕启动及系统状态灯进入正常心跳。
4. 检查画面、触摸、旋钮和时间；检查距离、温湿度及本次启用传感器是否有有效数据。
5. 需要联网时，在设备软件配置中选择网络并确认网络状态。离线是否允许测量，由本地保存配置决定，不能仅凭网络灯判断采集模块故障。

初始化完成前不要启动打印或把补光开到最大。状态灯初始化时先全灭再显示当前状态，不能把上一次残留颜色当作本次启动已完成。

### 4.2 测量准备

固定相机，保证目标在视场内且有可追踪纹理/标记。选择测点，确认标定文件、测量方向和位移单位。用ToF核对工作距离；ToF距离只能辅助换算，不代替镜头和测量平面的标定。

打开SW301，调到满足曝光的补光亮度。测量期间固定补光、曝光与增益；默认优先恒亮。若采用PWM调光，应确认当前曝光下没有条纹或帧间亮度波动。

旋钮缩放的是显示视图，不应重新定义已经标定的毫米/像素关系。显示倍率与标定比例应分别记录。

### 4.3 一次完整测量

1. 用触摸界面选择测点，或刷NFC测点标签完成测点关联。
2. 选择采集时间、分析方向、采样/帧率和报警阈值，确认其处于设备配置单的有效范围。
3. 开始采集，保持相机支架及目标周围条件稳定；测量灯绿闪表示正在采集。
4. 停止采集后等待计算；测量灯蓝色表示正在计算。
5. 检查位移波形、频谱、主频/幅值和质量标记。发生丢帧、追踪失败或饱和时，应按软件质量状态判断结果是否有效。
6. 保存结果及测点、时间、标定和采集条件；需要纸质记录时再执行打印。

记录应明确幅值采用峰值、峰峰值还是RMS，频率单位为Hz，位移单位按标定配置。没有质量合格结果时，不把上一次成功结果当成本次结果输出。

### 4.4 正常关机

停止采集，等待保存和打印结束；关闭补光。长按K101约3s提出关机请求，等待界面或软件提供“可以断电”的确认，再断开SW101。Linux关机不等于12V母线自动断电，本机没有自动切总电源的继电器。

意外拔电时PFAIL只能触发尽力停止新任务，电路没有为Linux完整关机或网络发送提供储能保持时间。正常关机应采用上述顺序。

## 5. 前面板状态灯与操作反馈

前面板HL101–HL105是五颗可编程RGB状态灯，由主应用决定语义，PL负责发送时序。主板HL201是独立硬件电源指示，不替代软件心跳。

| 灯 | 正常/活动显示 | 异常显示 |
|---|---|---|
| HL101 系统 | 黄：初始化；绿慢闪：软件心跳 | 红：系统故障 |
| HL102 网络 | 蓝闪：连接中；绿：已连接 | 黄：断开或连接失败 |
| HL103 测量 | 灭：待机；绿闪：采集；蓝：计算 | 黄：测量条件不满足 |
| HL104 外围 | 蓝短闪：读卡；黄闪：打印；绿短亮：成功 | 红闪：外围任务失败 |
| HL105 报警 | 低亮绿：正常 | 黄：预警；红：报警 |

显示优先级为故障、活动、短暂成功。静音后报警红灯保留，条件解除后按当前判级更新。系统心跳停止或画面无响应时，不仅根据其他灯残留绿色判断设备健康。

旋钮每圈有30个定位、15个电气脉冲；软件采用的x1/x2/x4解码会改变计数。应用应把“物理定位步数”转换为统一缩放步进，不能简单把一次边沿固定当作一个定位。按压消抖建议10–20ms；K101短按和长按只产生各自一次事件。

## 6. 补光、报警、风扇和语音

### 6.1 补光

J301驱动侧面约0.6m、15W/m的12V灯带，约9W；J304驱动左右两只12V/1W成品灯并联，总约2W。两只小灯同步工作，总共两路PWM，不是三路独立调光。

负载必须是自带限流/驱动、允许12V供电的成品灯。J301/J304的1脚是经各自保险的正端，2脚是MOS控制的负端；两组负端不可互相并接或直接接GND。裸大功率LED不能仅靠该MOS电路限流。

### 6.2 外部组合报警灯与蜂鸣器

组合灯需支持公共+12V、红/黄/绿及蜂鸣器四路独立低边控制。J302没有专用恒定GND触点。

| J302针号 | 连接 |
|---|---|
| 1 | 12V_ALM，在线束内分给SW302和SW303的输入 |
| 2 | 组合灯红色控制负端 |
| 3 | 组合灯黄色控制负端 |
| 4 | 组合灯绿色控制负端 |
| 5 | 组合灯蜂鸣器控制负端 |
| 6 | 风扇控制负端 |

SW302输出连接组合灯公共正极；SW303输出连接风扇正极，开关后的两根正极不再并接。控制负端按功能接，不按线色推断。“不分正负”的商品描述不能代替公共正极接线定义。

蜂鸣器为12V有源发声件，可以随组合灯采购；语音由另一只无源喇叭播放。软件应分别管理“报警条件存在”“本次报警已确认”“声音已静音”，避免确认后把未解除的报警误清除。

### 6.3 风扇

使用12V两线直流风扇，正端经SW303，负端接J302-6。选型电流及启动电流要计入与声光灯共用的F304支路。40×40×20mm、0.2A双滚珠款可作机械初选，是否安装由机壳空间和噪声决定。

J705是独立转速探头输入，不会自动测出两线风扇转速；软件发出FAN=1也不代表风扇实际转动。测量对气流敏感时，可按散热条件设置采集期间的固定风扇策略。

### 6.4 中文语音

J601连接一只8Ω、额定3W、两线无源动圈扬声器，可选带音腔和固定耳款。J601-1接喇叭正端，2接负端，两根线都不接GND。3W是喇叭承受功率，不代表5V/8Ω条件下保证输出3W。

预录语音以16kHz、16bit、单声道PCM WAV存放在J603卡中。主应用向Nano提交播放事件/编号，Nano读取文件、输出I2S，MAX98357A放大后发声。中文、英文等录音均可；任意文字即时朗读需要另外的软件语音合成能力，不属于预录文件播放功能。

播放时应先准备I2S数据并保持AMP_EN关闭，再打开功放；停止/静音时先降低音量或结束当前片段，再关闭AMP_EN。打印时限制语音音量或错开，避免叠加峰值负载。

音频文件名与播放编号由随固件交付的语音清单绑定。建议清单至少包含：测量完成、振动预警、振动报警、打印失败、存储异常；不能在未知文件映射时假设某个数字一定对应某条语音。

## 7. NFC测点识别

J602/J702/J703板端统一为讯普WAFER-GH1.25-8PWB（C3029383），使用与该板端配套的GH1.25八针带扣线束；针序按电气针号定义。

PN532 V3模块接J602，断电设置为SPI模式。对应Elechouse V3拨码是1号OFF、2号ON，按实际模块编号与ON标记确认。

| J602针号 | 模块丝印/用途 |
|---|---|
| 1 | VCC，5V_AUX |
| 2 | GND |
| 3 | SCK |
| 4 | MOSI |
| 5 | MISO |
| 6 | SS/SSEL |
| 7 | IRQ |
| 8 | NC，当前板未接线，模块RSTO不接 |

5V模块供电配合3.3V SPI信号。线束按丝印逐线对应，推荐不超过20cm。当前J602-8未引出RSTO，也没有RSTO测试点；不能通过它复位模块。

为每个测点配置一张兼容的13.56MHz标签，软件读取UID并绑定设备/测点编号。刷卡成功应显示本次识别的测点，并产生外围成功反馈；标签一直停留时应避免重复创建多条记录，移开后再刷按新事件处理。

读卡失败时检查模块模式、天线附近金属、线束、SPI事务及标签类型。卡片被读取只表示取得标识，不能替代测量条件确认。

## 8. 热敏打印

打印机型号为用户确认的EM5820H 12V版；TTL针序、串口参数和CTS行为仍需对照该批次接口说明。载板线束是PH2.0五针，按下表定义，不按最初的XH2.54描述购买线束。

| J401针号 | 打印机说明中的定义 | 实际方向 |
|---|---|---|
| 1 | VIN | 载板提供受控12V_PRN |
| 2 | CTS | 打印机输出；高忙、低可接收 |
| 3 | TX | 主机发送到打印机，HOST_TX |
| 4 | RX | 打印机发送回主机，HOST_RX |
| 5 | GND | 供电及信号回流 |

这里3/4脚已经按打印机资料中的“主机方向”定义，不再额外交叉。标准接法经五针VIN供电，不需要再接另一独立适配器。若某一具体机型要求走单独2针供电，必须使用仍受12V_PRN控制、正负回路匹配的配套线束，不能绕过载板受控电源。

执行打印前结束采集并关闭补光。由软件上电、等待就绪、打开串口通信后发送；用户等待打印完成再取纸或关机。不得仅凭CTS为低或UART发送队列为空判定纸张已经打印完。

打印纸宽、热敏面方向、波特率、校验位、命令集、缺纸查询方法与峰值电流应写入设备配置单。打印失败时查看缺纸、上盖、CTS超时和供电状态，不立即重复发送整单造成重复打印。

PH单个电源触点额定2A，VIN与GND都承受打印电流。装配与交付必须按实际打印机电流、线规和温升选定供电线束；2.5A PTC不等于对触点的2A精密限流。

## 9. 距离、IMU、温湿度和可选探头

### 9.1 ToF距离模块 J701

| 针号 | 信号 |
|---|---|
| 1 | VIN：3V3_SENS |
| 2 | GND |
| 3 | I2C1_SCL |
| 4 | I2C1_SDA |
| 5 | GPIO1：TOF_INT |
| 6 | XSHUT：XSHUT_OD，由主板开漏拉低 |

黑色六针VL53LXX-V2按实装芯片加载驱动，不仅看外壳丝印。VL53L0X和VL53L1X的I2C地址都为0x29；读型号后再选择对应程序。XSHUT只拉低或释放，TOF_DISABLE=1使其关断，0释放。距离无效、超量程或信号不足时，软件保留无效标志，不把0当作真实工作距离。

### 9.2 相机IMU J702

| 针号 | 模块功能 |
|---|---|
| 1 | 3V3_SENS |
| 2 | GND |
| 3 | SCL/SPC，用作SPI时钟SENS_SPI_SCLK |
| 4 | SDA/SDI，用作SPI MOSI，SENS_SPI_MOSI |
| 5 | SA0/SDO，用作SPI MISO，SENS_SPI_MISO |
| 6 | IMU_CS |
| 7 | INT1，数据就绪，经主板串阻返回 |
| 8 | INT2，经主板串阻返回 |

使用LSM6DSV模块，固定在相机支架上，用于记录相机运动。开机读取WHO_AM_I确认芯片，LSM6DSV预期0x70。输出轴方向、量程、采样率、滤波和时间戳必须随数据保存；加速度/角速度不能未经标定直接从像素位移中相减。

### 9.3 参考加速度计 J703，可选

1=3V3_SENS、2=GND、3=SENS_SPI_SCLK、4=SENS_SPI_MOSI、5=SENS_SPI_MISO、6=ADXL_CS、7=ADXL_DRDY_RAW、8不接。当前选用GY-291 ADXL345模块，贴在被测物上作对照。读取0x00的DEVID应为0xE5。使用SPI Mode 3，不能加载ADXL355驱动；模块SDO不得被0Ω电阻直接接地。共享总线的误识别I2C风险和资格测试见模块接入指南。

J702与J703共用SPI时钟、MOSI、MISO，各自独立片选；未选中的器件释放MISO。LSM6DSV从Mode 0、1MHz开始；ADXL345从Mode 3、1MHz开始。两CS全高时切换模式，绝不能同时选中两个设备。没有接参考加速度计时，保持ADXL_CS高。用J703扩展其他SPI设备时，还要核对电压、MISO释放及协议模式。

### 9.4 温湿度 J704

选SHT40模块，支持3.3V供电、I2C接口，当前驱动地址按0x44（AD1B等版本）。J704-1=3V3_SENS、2=GND、3=SCL、4=SDA。模块接口顺序不同时，按名称重排线束。

温湿度用于记录环境，不是直接测被测物表面温度。探头远离发热源并保持通风。常规测量不启用加热器；除湿加热后的读数需按传感器说明等待恢复，不能作为未受加热影响的环境温度直接使用。

### 9.5 转速 J705，可选

J705-1=5V_AUX、2=GND、3=SIG。探头应为支持5V供电、输出0～3.3V或0～5V脉冲的光电或霍尔模块。输入经过U401转换后送AX7010，不直接将12/24V信号接入。裸开集电极无自身上拉时安装R702=10k上拉；模块已有上拉或使用推挽输出时，先核对后决定，不重复随意装配上拉。

在转动部件设置反光标记或磁铁，软件配置每转脉冲数PPR。计算rpm=60×脉冲频率/PPR，转频Hz=rpm/60。只统计一个指定边沿，不把上升沿和下降沿都当作完整一转。无脉冲超时应显示停止或无有效测速，不能一直保留上次转速。

### 9.6 I2C扩展 J706

1=3V3_SENS、2=GND、3=I2C2_SCL、4=I2C2_SDA。首版可空置。扩展设备须为3.3V I2C接口并检查地址冲突；总线从100kHz开始，最高400kHz按线缆电容及上升时间确认。连接MLX90640时选3.3V兼容模块并配对应驱动，不将“预留接口”显示为已有热成像数据。

## 10. 数据、时间和网络

### 10.1 两处SD卡的区别

AX7010启动/系统存储与载板J603的MicroSD不是同一个接口。主测量结果写入AX7010应用配置的存储位置；J603由Nano管理，主要存放语音、配置和少量离线缓存，不承载相机高速原始数据。

J603卡的文件系统、容量范围和目录由Nano固件版本统一说明。开发初期可选FAT32兼容方案，但不能仅凭卡容量就假定所有固件都支持exFAT。系统运行时不要在写入或播放期间拔卡；先停止相关任务、关闭文件再取卡。

### 10.2 测量记录最低字段

| 类别 | 至少记录 |
|---|---|
| 标识 | 测量ID、设备ID、测点ID/标签UID |
| 时间 | 开始时间、时区、单调时钟/样本时间戳、时间同步状态 |
| 条件 | 相机模式、有效帧率、曝光、增益、补光通道/亮度 |
| 标定 | 标定编号、标定方向、位移单位、显示倍率单独记录 |
| 结果 | 主频、幅值及其峰值/峰峰值/RMS定义、波形/频谱引用 |
| 质量 | 丢帧、追踪状态、饱和、无效数据与报警判级 |
| 辅助 | 有效的距离、温湿度、IMU、可选参考加速度/转速及各自采样配置 |
| 版本 | 主应用、Nano、PL bitstream/硬件接口版本 |

记录格式和目录由软件项目统一；打印内容从同一份已保存结果生成，不能重新拿实时变量拼成与保存记录不一致的一张纸。

### 10.3 RTC与网络时间

载板DS3231作为整机记录时间源，CR1220维持断电走时，无充电电路。首次使用或更换电池后，由联网Nano/NTP或设置界面校时；网络时间不可用时，继续使用已有效的RTC并记录时间来源。

DS3231的1Hz方波用于秒级对齐和本地计数器校准，不是高采样率数据时钟。更新系统时间不能使采样的单调时间戳倒退。时区在应用层统一处理，保存记录时同时保留约定的时区信息。

Wi-Fi凭据、服务器地址及是否启用MQTT由设备软件配置，不固化在本指南。网络任务与语音/SD任务不应长时间阻塞采集控制链路。蓝牙功能若使用，按固件配置启用，不因芯片支持蓝牙就假定成品已有配对功能。

## 11. 清洁、维护与常见故障

断电后清理风道和镜头外表，保持ToF窗口、NFC刷卡面及温湿度探头通气。不要用清洗液浸湿传感器敏感窗口。更换镜头、相机安装位置或目标测量平面后重新确认标定；仅旋转显示缩放不触发重新标定。

| 现象 | 优先检查 |
|---|---|
| 整机不开机 | 适配器12V、SW101触点、输入线、F101及AX7010自身开关 |
| 屏幕亮但无图像 | HDMI连接、AX7010启动、显示模式/EDID |
| 有图像但无触摸 | AX7010 USB HOST到屏幕Touch的数据线和触摸驱动 |
| 旋钮或按键无响应 | GH10针序、AX_3V3、触点接地、PL输入/事件路径 |
| 灯带不亮 | SW301是否允许、LIGHT_OK、软件PWM、负载是否为12V成品灯、J301/J304线束 |
| 外部报警灯/蜂鸣器都不工作 | SW302、组合灯公共正极、J302负端定义及F304 |
| 报警灯亮但没有声音 | 软件静音、蜂鸣器控制与语音播放各自状态、语音文件及喇叭线束 |
| 风扇不转 | SW303、FAN请求、J302-6回路、风扇电压和启动电流 |
| NFC无法读卡 | SPI拨码、标签类型、天线金属遮挡、片选及位序切换 |
| SD与NFC单独正常、一起异常 | SPI事务位序/时钟、片选互斥、缓存和驱动是否修改全局设置 |
| 打印乱码 | 实际波特率/校验、命令集、HOST_TX/RX定义及信号地 |
| 打印时主控重启 | 12V母线与5V_AX最低值、负载错峰、线材触点、打印启动电流 |
| 有语音文件但无声 | AMP_EN、标准I2S格式、左右声道数据、WAV实际编码和J601 |
| 温湿度偏高 | 模块靠近发热源、通风、加热器是否启用 |
| ToF数值无效 | 实装芯片驱动、遮挡、目标反射、测量状态码及XSHUT |
| 结果频率/幅值不可信 | 有效帧率和丢帧、曝光、目标纹理、标定方向、相机支架及单位定义 |
| 掉电后时间丢失 | CR1220电量/极性、RTC有效状态及校时配置 |

维护记录至少包含故障现象、复现条件、版本、测量ID、供电/接口数据和处理结果。涉及线束换针后重新检查整个对应连接器，不仅检查换掉的单根线。

## 12. 开发职责与接口边界

本节用于软件、FPGA和硬件团队协作。它说明信号和行为，不替代各软件工程的API/协议定义。

| 模块 | 负责内容 | 向其他模块提供 |
|---|---|---|
| AX7010 PS/Linux | UI、视觉算法、配置、校准、存储、打印管理、报警判级、时间管理 | 测量任务、结果、显示状态、外设请求 |
| AX7010 PL | 相机/外围时序、输入同步、编码器与按键、PWM、WS2812、时间戳、AXI外设连接 | 数据及事件、可受控的外围接口 |
| Nano | Wi-Fi、NFC、辅助SD与I2S语音、网络时间获取 | 网络/卡/SD状态、UID、任务完成/错误、时间信息 |
| 主载板硬件 | 电源分配、缓冲/电平转换、保护、连接器及负载驱动 | 固定针序与有效电平 |
| 前面板小板 | 触点输入、五颗可编程灯 | 原始触点与级联LED，无独立固件 |

三路I2C、传感器SPI、两路UART从PL侧经AXI接口交给PS。实际使用AXI IIC/Quad SPI/UART16550或自定义IP由工程确定；Linux的/dev节点编号、AXI基地址、设备树compatible和中断号必须随bitstream与设备树一起交付，不能从接口名I2C0推断为/dev/i2c-0。

### 12.1 电平与有效状态

|---|---|---|
| LED_EN | 低允许补光 | SW301直接控制硬件驱动 |
| LIGHT_OK | 高=补光硬件允许 | Q306反相后的状态，读TCA P0.0 |
| LED1_PWM/LED2_PWM | 高点亮低边MOS | 100%为恒亮，0%为灭 |

| ESP_RESET | 高复位Nano | TCA P0.5，经Q601拉低NANO_RST |
| ESP_IRQ | 高表示Nano有事件 | 软件读取事件队列后按协议清除 |
| PFAIL_N / AX_PFAIL_N | 低表示掉电预警 | 停止启动新大负载和写入任务 |

### 12.2 TCA9555初始化及负载管理

U801七位I2C地址0x20。端口0输出为P0.4/5/6/7，其余输入；端口1输出为P1.0/1/2/3/5，其余输入。高电平使能的控制默认全部清零。

| 寄存器 | 地址 | 初始值/用途 |
|---|---|---|
| Input Port 0/1 | 0x00/0x01 | 读取LIGHT_OK和INA_ALERT等输入 |
| Output Port 0/1 | 0x02/0x03 | 先写0x00/0x00 |
| Polarity Inversion 0/1 | 0x04/0x05 | 0x00/0x00，不在芯片内部反相 |
| Configuration 0 | 0x06 | 0x0F，1为输入、0为输出 |
| Configuration 1 | 0x07 | 0xD0，P1.4/P1.6/P1.7输入 |

初始化按“先写输出锁存器为0，再切输出方向”的顺序；对寄存器读写错误要返回明确故障，不把未成功配置当成已关负载。后续写输出使用软件影子值/锁保护，只修改目标位，避免并发任务互相覆盖打印、报警和风扇状态。

| 位 | 功能 |
|---|---|
| P0.0 | LIGHT_OK，输入 |
| P0.1/P0.2/P0.3 | 保留输入 |
| P0.4 | TOF_DISABLE |
| P0.5 | ESP_RESET |
| P0.6 | PRN_PWR_EN |
| P0.7 | PRN_COM_EN |
| P1.0/P1.1/P1.2 | ALM_R/ALM_Y/ALM_G |
| P1.3 | BUZZ |
| P1.4 | 保留输入，不能当作风扇控制 |
| P1.5 | FAN |
| P1.6 | INA_ALERT，输入 |
| P1.7 | 保留输入 |

读取Input寄存器并按手册清除/释放INT条件；对负载输出寄存器的写入只说明请求已写入，不等于执行器已经动作。

### 12.3 启动、掉电与重配置

启动时PL输出按既定下拉保持补光与数据默认态，PS接管后先关打印发送和电源，初始化TCA、读取设备身份、初始化Nano任务、发送前面板全灭帧，再进入待机。

PL重配置前，PS停止采集和外设任务、关闭打印通信/电源及需要关闭的负载、发送灯灭帧。TCA寄存器和WS2812颜色不会因为重配置自动清空。重配置后重新建立IP映射、输入同步及驱动状态，不能继续使用旧设备节点和失效映射。

PFAIL_N约在12V下降到10.8V触发，回升到约11.2V恢复，阈值有器件误差。PS和Nano应停止新打印、降低负载并停止新存储写入；没有储能保持时间保证时，不把掉电中断当作必定能完成的保存窗口。回升后按任务状态重新初始化，不把中断的打印自动无条件重发。

### 12.4 I2C与传感器SPI

| 总线 | 设备七位地址/片选 | 电源及起步配置 |
|---|---|---|
| I2C0 | TCA9555 0x20；INA226 0x40；DS3231 0x68 | AX_3V3，上拉4.7k，100kHz |
| I2C1 | ToF 0x29；SHT40 0x44 | 3V3_SENS，上拉与模块并联，100kHz |
| I2C2 | 扩展，接MLX90640时通常0x33 | 3V3_SENS，100kHz；最高400kHz按波形确认 |
| 传感器SPI | IMU_CS、ADXL_CS独立 | 3.3V逻辑；LSM6DSV Mode 0，ADXL345 Mode 3，均1MHz起步 |

I2C控制器以开漏方式工作，释放表示高电平，不能推挽强驱SCL/SDA为高。0x20等均是七位地址，不手动再左移成软件API中的地址。串阻前后应保持不同网络：SENS_SPI_SCLK/MOSI在模块侧，SPI_SCLK/MOSI在FPGA侧；SENS_SPI_MISO经R707=1k到SPI_MISO。

在PL记录DRDY到达时刻，随后读取样本；读取完成时刻不等于样本产生时刻。共享SPI访问需要串行化和超时处理；片选拉高后满足器件关闭时序，再选另一个设备。只改总线时钟而不改传感器ODR，不会改变真实采样率。

### 12.5 Nano与AX7010串口

| 功能 | AX7010 J11 | Nano |
|---|---|---|
| PS/PL发送 | 19，ESP_TXD | D3/GPIO6接收 |
| PS/PL接收 | 20，ESP_RXD | D2/GPIO5发送 |
| AX发出的RTS | 21，ESP_RTS | D5/GPIO8，Nano CTS |
| AX读取的CTS | 22，ESP_CTS | D4/GPIO7，Nano RTS |
| Nano事件 | 23，ESP_IRQ | D6/GPIO9输出 |

波特率以固件配置为准，方案起步值为921600bps；8N1可作为联调配置但需两端一致。RTS/CTS按UART常用低电平允许接收约定配置，并用实际驱动验证；不能仅看RTS/CTS名字认为电平和软件库参数必然相同。

通信至少传递以下语义：握手与版本、网络状态、NFC UID/测点事件、SD状态、语音播放请求/完成/失败、时间同步、任务错误。本资料包另附PS—Nano协议V1开发约定和Python参考编解码器；它们是新开发接口约定，尚未烧录到实板。

接口实现应有消息长度上限、事务标识/结果、有限超时和可恢复的重连。IRQ仅表示“有事件”，事件内容仍从UART读取；不要每个IRQ都假定为一次刷卡。长任务返回进度或忙状态，不阻塞通信接收。

### 12.6 Nano的SD/NFC共享SPI与语音

Nano SPI：D13/GPIO48=SCLK，D11/GPIO38=MOSI，D12/GPIO47=MISO；D10/GPIO21=SD_CS，A3/GPIO4=PN_CS。U601按各CS选通回传MISO，两个CS不能同时为低。

SD使用高位先传，初始化约400kHz，之后先验证4MHz；PN532使用Mode 0、低位先传，建议从1MHz验证，不超过模块/芯片5MHz上限。每次事务设置对应速度、模式和位序，并在完成后释放片选。厂家旧版PN532驱动修改SPI全局配置，需审查与SD驱动的事务兼容，不能直接拼接示例。

语音播放从SD取数据，NFC也要访问同一总线；使用互斥访问和音频缓冲，读卡不能造成音频长期欠载，音频任务也不能长期占住总线。J603机械检测为低表示卡插入；它与DAT3/CS是两个不同信号。

I2S：D7/GPIO10=BCLK，D8/GPIO17=LRCLK，D9/GPIO18=DIN；A7/GPIO14=AMP_EN。MAX98357A接标准I2S，可用16kHz采样、双声道32bit时隙，左右复制同一单声道数据，此时BCLK为1.024MHz。R617=510kΩ使SD_MODE进入左右平均输出区间；固件不要将其当作直接3.3V数字输入改接。

### 12.7 前面板输入和WS2812

ENC_A/ENC_B、ENC_SW及FP_KEY到PL后先做两级同步，再进行合法正交状态解码和按键消抖。非法跳变不作为有效步进。长按事件触发后释放不能再重复发短按；旋钮显示方向可在软件反向，不更改线束标准针序。

五颗WS2812B-V6依次HL101→HL105，GRB每颗24bit、高位先发，帧间低至少300µs。参考100MHz PL时钟，0码高/低30/95周期，1码65/60周期，周期均1.25µs。实际逻辑时钟改变时重新换算计数，不照抄周期数。上电先全灭，再按状态更新；默认全局亮度可从32/255起步，按可读性和电流配置。

主应用统一状态，多个任务不得直接争写LED帧。若设计心跳超时显示，应由PL/状态服务检测主应用心跳失效并按固件配置显示异常；WS2812自身不会因数据停止而自动变红。

### 12.8 打印控制状态机

推荐状态：断电、上电等待、就绪、发送、等待打印完成、关闭通信、断电等待、故障。核心顺序如下：

```text
停止采集并关闭补光
→ PRN_COM_EN=0，停止/屏蔽打印接收
→ PRN_PWR_EN=1
→ 等待受控上电、打印机厂家启动时间，并确认CTS允许
→ 清接收缓存和UART错误标志，启用接收
→ PRN_COM_EN=1，按CTS发送
→ 按打印机协议确认任务真正完成
→ PRN_COM_EN=0，禁用接收
→ PRN_PWR_EN=0，等待规定的最小断电间隔
```

启动超时、CTS持续忙、缺纸或电源故障应停止发送、报告原因并进入可恢复状态。PRN_PWR_EN下降不代表打印机已经失电；RC时间常数不等于打印机复位时间。最小重启间隔和启动超时从设备配置读取，不使用未经验证的固定几十毫秒。

### 12.9 时间与功率监测

INA226：0x40，5mΩ分流，Current_LSB=0.25mA时CAL=4096。5A对应25mV与0.125W，取样正方向为12V_PROTECTED流向12V_MAIN。驱动重置后重新写校准值；采样平均值不能代表打印头微秒级峰值。

DS3231：0x68，配置INTCN=0、RS=00输出1Hz，BBSQW=0；校时前检查振荡停止/时间有效状态，应用统一清除和记录处理。电池不充电。

功率管理参考：约4.2A输入告警、接近4.5A不再启动新的大负载任务，阈值写入设备配置并结合打印波形确定。默认关闭补光后打印；语音和风扇等负载仍需计入。基础采集约28.7W、关补光打印约41.7W/53.7W只是假设2A/3A打印的预算，不是已保证的整机功率或接口载流能力。
