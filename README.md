## 当前实现与限制

PS Linux运行采集、测振、屏幕UI和主记录；PL已承担相机、HDMI、双目和PDM接收，完整实时位移跟踪仍主要在PS；Nano负责NFC、辅助SD、语音、Wi-Fi/NTP与APP网关。目标架构见[三侧分工](03_设计说明/PL_PS_ESP32职责与接口分工.md)。

此前板端冻结为`freeze-20261025-capture-near-stereo`，4测点4参考、约45fps采集、双目0–127视差搜索。20cm可靠准确测距尚未验收，名义标定不等于正式棋盘格标定。机位或测量框改变后需重采停机基线。

当前main包含后续APP接口；Nano的bin仍是旧固件，不能把它当作最新源码构建结果。三侧主协议可对应，105项主机集成通过，但APP声学字段与连续设置有已复现问题，尚未修复；载板PL、串口及外设整机联调仍待完成。这里的资料整理不表示完成上述验收。
