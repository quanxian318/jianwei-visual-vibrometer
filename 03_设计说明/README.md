视觉测振主链采用实体散斑/纹理、测点与静止背景参考、停机基线、跟踪质量和频谱分析。当前多点位移计算仍在PS；PL位移累加核有仿真证据，完整实时搜索/接口尚未接入。双目Census/SGM已运行于PL；深度依赖正式相机标定，不能把显示填补当作实测距离。

声学链为MP34DT01→PL PDM接收与计时→PS抽取/包络谱→与视觉频率独立对照，不换算成振动位移。LED1接照明，LED2接12V/650nm十字投影，默认位移采集时关闭投影。固定投影不等同跟随材料运动的实体散斑。
