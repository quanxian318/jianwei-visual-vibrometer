# 屏幕、触屏与编码器操作说明

屏幕和触屏由 AX7010 的 PS/Linux 程序 vibmond 控制（`src/ui`），输出到 framebuffer `/dev/fb0`，触摸读 `/dev/input/event*`。EC11 和 K1 由 PL 译码后经事件 FIFO 上报。下列截图均为主机用合成数据渲染（`tests/test_render.cpp`），不是上板截图。

## 布局

1024×600 深色界面：顶部状态栏，左侧六个页面导航，右侧内容区。状态栏从右到左显示时间（未校时为黄色 `--:--:--`）、电压电流（掉电预警变红）、网络、当前测点、激光开启时的红色“激光”，以及预警/报警图标（静音后显示静音图标）。界面约 8 帧/秒刷新，手指按下时立即重画按下效果；界面刷新率不是相机采样率。

| 页面 | 内容 |
|---|---|
| 实时 | 相机预览（双线性缩放）、测点框/十字准星、采集状态、显示缩放 −/＋/复位；实时位移曲线；大号开始/停止按钮，带采集进度环；测量时长 5/10/30/60 s；实时位移、相关度、帧率、工作距离；照明（J301）、十字投影（J304）、报警静音、振动热力叠加 |
| 结果 | 主频、峰峰值、有效值、判级四张卡片；编号、时间、测点、帧率、丢帧、抖动、最低相关、标定；位移波形和幅值谱（标出主频）；打印报告、再测一次。从记录页进入时显示该条记录，并有“返回记录” |
| 视觉 | 三种显示：运动放大（原始/放大并排）、振动热力（带通幅值伪彩，标出最强振动点）、双目深度（深度伪彩、近远色标、点按查看距离、测点处距离，可在此开关十字线投影）。可选频带 0.5–2/2–5/5–10/10–20 Hz 或跟随主频，放大 ×5/×10/×20/×50；右侧显示处理端（PS 软件/PL 硬件）、分辨率、帧率、每帧耗时和滤波是否稳定 |
| 记录 | 本机保存的测量记录，新的在前，每页 8 条，显示时间、编号、测点、主频、峰峰值、有效值、判级；点一行打开结果页 |
| 设备 | 16 块状态卡：PL 载板、电源监测、负载控制、时钟、相机、Nano、Wi-Fi、语音 SD、NFC、打印机、IMU、参考加速度计、测距、温湿度、风扇与转速、照明与激光（含 SW301 是否允许）；整机电源条（标出预警和禁止大负载阈值）；应用/PL/Nano 版本 |
| 设置 | 测量时长、测点框尺寸、位移方向、测量自动照明、照明亮度、测量时关闭激光、预警/报警阈值、蜂鸣器、语音及音量、风扇模式、前面板灯亮度；Wi-Fi 配置（屏幕键盘）；关机（需确认） |

## 触屏

点按在手指抬起时生效，且必须在按下位置附近（24 像素内）抬起；左右滑动超过 140 像素切换上一页/下一页（对话框打开时不切换）。灰色控件不响应；所有动作走 `Application::command()`，与 vibmonctl 相同，主控仍会再次检查互锁。命令被拒绝时底部提示原因（如“相机未就绪”“打印机工作中”）。

在实时页预览上点按，或在视觉页的放大/热力图上点按，可把该位置设为下一次测量的测点中心；采集和计算期间不能改。缩放后点按会换算回原图坐标，显示缩放和运动放大都不参与毫米换算。

照明和激光是两路独立输出：照明可调亮度；激光固定 100% 输出、只开关。两路都需要 SW301 硬件允许，打印、掉电和关机时都会关闭。“测量时关闭投影”默认打开：开始测量时自动关激光、结束后恢复，因为固定投影图案不保证随被测表面平移，留在测点框内会把位移拉向零；只有在开始前做投影相关实验设置时才关掉这个选项；采集和分析期间不能更改，启用关闭策略时不能从实时页、视觉页或命令行重新开启投影。

设置页的修改立即生效，并保存到 `storage.settings_file`（默认 `/home/root/vibmon/settings.json`），下次启动时覆盖 vibmon.json 中的同名项。非法组合（如预警阈值不低于报警阈值）整体拒绝；采集中不能改时长、测点框和方向；已加载标定时位移方向由标定决定。Wi-Fi 名称和密码通过 SET_NET 交给 Nano 保存，主程序不保存密码。

## 编码器与独立按键

| 操作 | 功能 |
|---|---|
| EC11 旋转 | 实时页：显示缩放（每档 ×/÷1.25，1–8 倍）；记录页：翻页；其他页无动作 |
| EC11 短按 | 实时页：缩放复位；其他页：回到实时页 |
| EC11 长按 | 依次切换到下一页 |
| K1 短按 | 静音蜂鸣器并停止当前语音，保留报警等级灯 |
| K1 长按 | 默认 3 秒发起关机 |

没有屏幕（framebuffer 打不开）时，EC11 旋转和短按仍控制显示缩放。每档电气计数、方向可在 `panel.encoder_counts_per_detent`、`panel.encoder_reverse` 配置，顺/逆时针的最终对应需实物确认。

## 视觉页的数据来源

运动放大和振动热力来自视觉处理链（`src/measure/vision.cpp`）：相机灰度经高斯金字塔降采样到不超过 200 像素宽的工作图，对拉普拉斯带逐像素做时间带通。当前在 PS 上以独立线程运行；测量采集和计算期间暂停，不与位移跟踪争 CPU，页面显示“测量期间暂停”。同一算法的 PL 实现见 `ax7010/pl/vision`，接入后页面的处理端显示“PL 硬件”。放大画面只用于显示，不参与计量。

双目深度由双目模块通过 `Application::publishDepth()` 提供（毫米深度图，0 为无效，可附左目图像）；超过 3 秒没有新数据视为未接入，页面显示“双目深度未接入”。

## 尚未验证

实体屏幕的 framebuffer 格式、触摸设备识别、方向与边缘精度、ARM 上的刷新耗时，以及 PS 视觉线程在 AX7010 上的实际每帧耗时，都需上板确认。
