# 成品使用与开发指南

当前接线、所选模块与购物链接先读[整机逐引脚装配](整机装配_逐引脚接线与模块互连.md)、[采购链接](已选模块_采购链接与规格.md)及[手册覆盖](数据手册与资料覆盖核对.md)。

这份指南按成品操作与接口编写，不记录原理图绘制进度。普通使用者先读第1—11章；软硬件开发者继续读第12—14章及针序附录。

- [浏览器阅读版](主载板与前面板成品使用及开发指南_V1.0.html)：带目录，可通过“打印/保存为PDF”导出。
- [Markdown源文档](主载板与前面板成品使用及开发指南_V1.0.md)：便于团队维护和版本管理。
- [接口速查](主载板与前面板接口速查.csv)：186行针脚定义，跨板引用包含板件名称。
- [设备配置单模板](设备配置单模板.csv)：45项设备、软件、标定、外设和电气配置。
- [成品功能验收记录模板](成品功能验收记录模板.csv)：26项功能与电气验收，填写实际数据和证据路径。

成品具体测量指标、软件协议帧、Linux设备映射、打印机参数及语音编号由对应交付配置填写；不把手册示例当作现成软件API或测量保证值。

更新接口时同时维护指南、接口CSV和源设计中的对应契约。主板J101与前面板J101不是同一个接口；J306及带灯按钮接法已纳入本指南。
